كورس مدفوع: تعلم أساسيات بناء المنظومات

كورس تعلم المنظومات وقواعد البيانات الضخمة وكيفية التعامل مع مستودعات البيانات ضمن سلسلة أساسيات التقنية تحت إشراف الكاتبة والمهندسة مها شهوب.

01
language C#

Visual Studio language #C

تطوير المنظومات الإدارية والتجارية الضخمة، وبناء أنظمة برمجية متكاملة لإدارة الشركات، المخازن، والمبيعات، مع توفير واجهات مستخدم ذكية وحماية عالية للبيانات.

02
Structure Query Language

SQl Server language SQl

تطوير مهارات التعامل مع قواعد البيانات الرابطية، واكتساب القدرة على تصميم الجداول، وبناء العلاقات البرمجية، وكتابة الأوامر والسيناريوهات المتقدمة لإدارة البيانات بذكاء.

03
Database Management System

نظم إدارة قواعد البيانات

إدارة وتأمين قواعد البيانات للمنظومات، وضمان استمرارية عملها بدون انقطاع، مع تنظيم النسخ الاحتياطي، وحماية معلومات المؤسسة من الفقدان أو الاختراق.

04
Data Warehouses

مستودعات البيانات

بناء مستودعات البيانات الضخمة، وتجميع المعلومات من مصادر متعددة وتنقيتها، لمساعدة المؤسسات على تحليل الأداء التاريخي واتخاذ قرارات إستراتيجية ذكية بناءً على تقارير دقيقة.

05
User Interface and User Experience (UI/UX) Design

تصميم واجهات المستخدم وتجربة المستخدم (UI/UX)

تعلم المبادئ الأساسية لبناء واجهات مريحة وتجربة مستخدم سلسة، تركز على تسهيل إدخال البيانات، وتسريع التنقل بين القوائم، وتصميم شاشات واضحة تقلل من الأخطاء البشرية أثناء العمل على المنظومة .
