01 — مقدمة VB.NET

VB.NET (Visual Basic .NET) لغة برمجة من عائلة لغات .NET، وتستخدم لبناء تطبيقات سطح المكتب، تطبيقات قواعد البيانات، الأدوات الداخلية، والخدمات والتطبيقات التي تعمل ضمن منظومة .NET.

VB.NET
لغة البرمجة وكتابة الكود.
.NET
منصة تشغيل ومكتبات وأدوات تطوير.
Visual Studio
بيئة تطوير متكاملة IDE.
NuGet
مدير حزم لإضافة المكتبات.

VB6 وVB.NET

VB.NET ليست مجرد نسخة محسنة من VB6؛ إنها جزء من منظومة .NET وتدعم OOP والأنواع الحديثة والمكتبات المشتركة مع .NET. لذلك يجب التفريق بين مشاريع VB6 القديمة ومشاريع VB.NET الحديثة.

Module Program
    Sub Main()
        Console.WriteLine("Hello, VB.NET!")
    End Sub
End Module

02 — Visual Studio والمشاريع

09 — Functions وSub

Sub تنفذ إجراءً ولا ترجع قيمة، بينما Function ترجع قيمة.

Sub ShowMessage(message As String)
    Console.WriteLine(message)
End Sub

Function Add(a As Integer, b As Integer) As Integer
    Return a + b
End Function

Dim result = Add(10, 20)
ShowMessage(result.ToString())

ByVal وByRef

ByVal يمرر قيمة المعامل، أما ByRef فيسمح للدالة بتعديل المتغير المرسل إليها مباشرة. استخدمي ByRef فقط عندما يكون ذلك مقصوداً.

10 — OOP والكلاسات

البرمجة الكائنية OOP تبني البرنامج حول كائنات تجمع البيانات والسلوك.

Public Class Student
    Public Property Name As String
    Public Property Age As Integer

    Public Sub New(name As String, age As Integer)
        Me.Name = name
        Me.Age = age
    End Sub

    Public Function GetInfo() As String
        Return $"{Name} - {Age}"
    End Function
End Class

Dim s As New Student("Maha", 30)
Console.WriteLine(s.GetInfo())

12 — معالجة الأخطاء Exceptions

Try
    Dim number As Integer = Integer.Parse("123")
    Console.WriteLine(number)
Catch ex As FormatException
    Console.WriteLine("القيمة ليست رقماً صحيحاً")
Catch ex As Exception
    Console.WriteLine(ex.Message)
Finally
    Console.WriteLine("انتهت العملية")
End Try
مهم: لا تستخدمي Catch Exception لإخفاء الأخطاء. سجلي الخطأ وتعاملِي معه حسب نوعه، ولا تعرضي تفاصيل حساسة للمستخدم النهائي.

15 — LINQ

LINQ تسمح بكتابة استعلامات على المجموعات والكائنات ومصادر بيانات مختلفة بطريقة موحدة.

Dim numbers = New List(Of Integer) From {1,2,3,4,5,6}

Dim evenNumbers = numbers.Where(Function(x) x Mod 2 = 0).ToList()

For Each n In evenNumbers
    Console.WriteLine(n)
Next

OrderBy وSelect

Dim names = New List(Of String) From {"Maha", "Ali", "Sara"}

Dim result = names.
    OrderBy(Function(x) x).
    Select(Function(x) x.ToUpper()).
    ToList()

16 — Async وAwait وTasks

البرمجة غير المتزامنة تساعد التطبيق على تنفيذ عمليات انتظار مثل الشبكة أو الملفات دون تجميد واجهة المستخدم.

Imports System.Threading.Tasks

Async Function LoadDataAsync() As Task(Of String)
    Await Task.Delay(1000)
    Return "تم تحميل البيانات"
End Function

Async Function RunAsync() As Task
    Dim result = Await LoadDataAsync()
    Console.WriteLine(result)
End Function
في Windows Forms، استخدمي Await للعمليات الطويلة مثل طلبات API أو قواعد البيانات لتقليل تجمد الواجهة.

20 — HTTP وREST وAPIs

يمكن لتطبيق VB.NET الاتصال بخدمات الويب باستخدام HttpClient وإرسال GET وPOST وغيرها، ثم قراءة JSON.

Imports System.Net.Http

Async Function GetDataAsync() As Task(Of String)
    Using client As New HttpClient()
        client.Timeout = TimeSpan.FromSeconds(30)

        Dim response = Await client.GetAsync("https://example.com/api/users")
        response.EnsureSuccessStatusCode()

        Return Await response.Content.ReadAsStringAsync()
    End Using
End Function
في المشاريع الحقيقية استخدمي HTTPS، وتحققي من الاستجابات والأخطاء، ولا تضعي مفاتيح API السرية داخل الواجهة أو المستودع العام.

21 — MySQL وADO.NET

يمكن ربط VB.NET بقاعدة MySQL عبر مكتبة مناسبة مثل MySqlConnector أو Oracle MySql.Data. يجب الالتزام بتوثيق المكتبة المستخدمة لأن أسماء بعض الأنواع وواجهاتها تختلف.

اتصال باستخدام MySqlConnector

Imports MySqlConnector

Dim cs As String =
    "Server=localhost;Database=school;User ID=appuser;Password=YOUR_PASSWORD;"

Using con As New MySqlConnection(cs)
    con.Open()

    Using cmd As New MySqlCommand(
        "SELECT id, name FROM students WHERE age >= @age", con)

        cmd.Parameters.AddWithValue("@age", 18)

        Using reader = cmd.ExecuteReader()
            While reader.Read()
                Console.WriteLine(reader("name").ToString())
            End While
        End Using
    End Using
End Using

INSERT آمن

Using cmd As New MySqlCommand(
    "INSERT INTO students(name, age) VALUES(@name, @age)", con)

    cmd.Parameters.AddWithValue("@name", txtName.Text.Trim())
    cmd.Parameters.AddWithValue("@age", Integer.Parse(txtAge.Text))

    cmd.ExecuteNonQuery()
End Using
قاعدة أساسية: استخدمي Parameters بدلاً من دمج مدخلات المستخدم داخل SQL لتقليل خطر SQL Injection.

22 — Entity Framework Core

EF Core هو ORM يسمح بالتعامل مع قواعد البيانات من خلال الكائنات بدلاً من كتابة كل SQL يدوياً. اختيار مزود MySQL يعتمد على قاعدة البيانات والمكتبة المستخدمة في المشروع.

Public Class Student
    Public Property Id As Integer
    Public Property Name As String
    Public Property Age As Integer
End Class

Public Class AppDbContext
    Inherits DbContext

    Public Property Students As DbSet(Of Student)

    Protected Overrides Sub OnConfiguring(
        optionsBuilder As DbContextOptionsBuilder)

        optionsBuilder.UseMySql(
            "Server=localhost;Database=school;User ID=appuser;Password=YOUR_PASSWORD;",
            ServerVersion.AutoDetect(
                "Server=localhost;Database=school;User ID=appuser;Password=YOUR_PASSWORD;"))
    End Sub
End Class
تحققي من إصدار EF Core وموفر MySQL المستخدم قبل نسخ الكود إلى مشروع فعلي، لأن API والإعدادات قد تتغير بين الإصدارات.

23 — الأمان والتحقق

SQL Injection
استخدمي Parameters.
Passwords
لا تخزني كلمات المرور كنص صريح؛ استخدمي hashing مناسباً.
Secrets
لا تضعي كلمات المرور ومفاتيح API في الكود المنشور.
Validation
تحققي من المدخلات قبل المعالجة والحفظ.
Least Privilege
امنحي حساب قاعدة البيانات الصلاحيات اللازمة فقط.
TLS
استخدمي اتصالات مشفرة عند نقل البيانات الحساسة.

Using client As New TcpClient()

29 — الاختبار والتصحيح والأداء

Debugging

  • Breakpoints لإيقاف التنفيذ.
  • Watch لمراقبة المتغيرات.
  • Immediate Window للتجارب أثناء التصحيح.
  • قراءة Stack Trace لمعرفة مسار الخطأ.

تحسين الأداء

  • تجنبي العمليات الثقيلة على UI Thread.
  • استخدمي Async/Await للعمليات الانتظارية المناسبة.
  • استخدمي استعلامات محددة بدلاً من جلب بيانات غير ضرورية.
  • أضيفي Indexes مناسبة في قاعدة البيانات.
  • لا تفتحي اتصالات قاعدة البيانات دون داعٍ.
  • استخدمي Using أو Using ... End Using لإدارة الموارد القابلة للتخلص.
Using con As New MySqlConnection(connectionString)
    con.Open()
    ' تنفيذ العمل
End Using
