01. مقدمة في CSS

لغة Cascading Style Sheets هي المسؤولة عن تصميم المظهر الجمالي وتوزيع العناصر لفصل الهيكل (HTML) عن الشكل البصري لجعل صيانة المواقع أسهل بكثير.

02. تركيب قواعد CSS

تتكون القاعدة من محدد (Selector) وكتلة إعلانات بين قوسين مجعدين تحتوى على الخاصية (Property) والقيمة (Value).

selector {
  property: value;
}

03. طرق تضمين CSS

يمكن تضمين التنسيقات بثلاث طرق: داخلية عبر الوسم style، مضمنة (Inline) داخل العنصر، أو خارجية عبر ملف مستقل.

<link rel="stylesheet" href="style.css">

04. المحددات البسيطة (Selectors)

تستهدف عناصر الـ HTML مباشرة عبر كتابة اسم الوسم العام مثل الفقرات أو العناوين الرئيسية.

p {
  color: #333;
}

05. محددات العناصر والفئات (Classes & IDs)

الفئات تستخدم لنقاط التكرار باستخدام النقطة (.), بينما المعرفات (IDs) فريدة وتستخدم بالرمز (#).

.card { background: #fff; }
#main-header { padding: 20px; }

06. المحددات المركبة والمجموعات

تطبيق نفس كود التنسيق على عدة عناصر مختلفة دفعة واحدة عن طريق فصلها بالفواصل.

h1, h2, h3 {
  color: #0b4f88;
}

07. المحددات التابعة (Descendant & Child)

استهداف العناصر المتواجدة حصرياً داخل أب أو حاوية معينة لتجنب تأثير باقي عناصر الصفحة.

div > p {
  font-size: 14px;
}

08. محددات الحالات (Pseudo-classes)

التحكم بتغير شكل العناصر بناءً على حالة تفاعل المستخدم مثل المرور بالفأرة أو الضغط.

a:hover {
  color: #1677c8;
  text-decoration: underline;
}

09. محددات العناصر الوهمية (Pseudo-elements)

إضافة وتصميم أجزاء غير موجودة في الـ HTML الأصلي مثل الحرف الأول أو الرموز التعبيرية.

p::first-letter {
  font-size: 2em;
  font-weight: bold;
}

10. الخصائص والوراثة (Inheritance)

آلية ترث من خلالها العناصر الابنة بعض خصائص الأب (مثل خصائص النصوص والخطوط تلقائياً).

body {
  font-family: "Segoe UI", Tahoma, sans-serif;
}

11. الخصوصية وقوة المحددات (Specificity)

نظام الحساب الرياضي للمتصفح لتحديد أية قاعدة تُطبق عند تداخل الأكواد (IDs أقوى من Classes وأقوى من الوسوم).

12. ألوان CSS (HEX, RGB, HSL)

طرق تمثيل الألوان برمجياً، سواء بالنظام السداسي عشري، أو نظام الألوان الأحمر والأخضر والأزرق.

.box {
  background-color: rgb(22, 119, 200);
}

13. الوحدات المطلقة (px, cm)

وحدات قياس ثابتة لا تتغير مهما تبدلت أبعاد شاشة العرض، وأشبرها البيكسل (px).

.element {
  width: 300px;
}

14. الوحدات النسبية (em, rem, %)

قياسات مرنة تتكيف بناءً على حجم خط العنصر الأب (em) أو خط الجذر الأساسي (rem).

html { font-size: 16px; }
h1 { font-size: 2rem; /* يعادل 32px */ }

15. وحدات الشاشة (vw, vh, vmin)

قياسات تعتمد بشكل مباشر على نسبة مئوية من عرض (vw) أو ارتفاع (vh) شاشة المتصفح.

.hero {
  height: 100vh;
}

16. نموذج الصندوق الأساسي (Box Model)

العمود الفقري لتصميم الويب والذي يتعامل مع كل عنصر على أنه صندوق مؤلف من محتوى وحشوة وحدود وهوامش.

17. خاصية Box-Sizing

استخدام قيمة border-box تضمن عدم تمدد عرض الصندوق عند إضافة الحشوة والحدود.

* {
  box-sizing: border-box;
}

18. الهوامش الخارجية (Margin)

التحكم في المساحات الفارغة المحيطة بالعنصر من الخارج، وتستخدم لتوسيط العناصر أفقياً بـ auto.

.container {
  margin: 20px auto;
}

19. الحشوة الداخلية (Padding)

المسافة الفارغة الواقعة بين محتوى العنصر الداخلي وحدوده الخارجية لزيادة الراحة البصرية.

.card {
  padding: 15px 25px;
}

20. الحدود (Borders) وأنواعها

التحكم في سمك، نمط (متصل، منقط، مزدوج)، ولون الإطار المحيط بالعنصر.

.box {
  border: 1px solid #d7e1eb;
}

21. الزوايا الدائرية (Border-Radius)

إعطاء انحناء لزوايا الصناديق والبطاقات، أو تحويلها إلى دوائر تامة.

.avatar {
  border-radius: 50%;
}

22. العرض والارتفاع (Width & Height)

تحديد الأبعاد الأساسية للعناصر والحاويات على الشاشة.

.box {
  width: 100%;
  height: 200px;
}

23. أقصى وأدنى الأبعاد (Min/Max)

حماية التخطيط من الانهيار عبر وضع قيود دنيا وعليا للعرض والارتفاع.

.container {
  max-width: 1200px;
  min-height: 400px;
}

24. أنواع العرض (Display)

التحكم بسلوك ظهور العنصر، هل يشغل سطراً كاملاً (block) أم يتقاسم السطر (inline).

.element {
  display: block;
}

25. الإخفاء والظهور (Visibility & Display)

الفرق بين إخفاء العنصر تماماً وإلغاء مساحته (display: none) أو إخفائه مع الحفاظ على فراغه (visibility: hidden).

.hidden {
  display: none;
}

26. التموضع النسبي (Relative)

إزاحة العنصر قليلاً عن مكانه الأصلي دون التأثير على تدفق باقي عناصر الصفحة.

.box {
  position: relative;
  top: 10px;
}

27. التموضع المطلق (Absolute)

إخراج العنصر من التدفق الطبيعي وتثبيته بدقة إحداثية داخل أب يمتلك تموضعاً نسبياً.

.badge {
  position: absolute;
  top: 0;
  right: 0;
}

28. التموضع الثابت والملاصق (Fixed & Sticky)

تثبيت العناصر (مثل الهيدر العلوي) أثناء عملية التمرير في الصفحة.

header {
  position: fixed;
  top: 0;
  width: 100%;
}

29. طبقات التراكب (Z-Index)

التحكم بأي العناصر تظهر في المقدمة وأيها تقع في الخلف عند تداخل العناصر المتموضعة.

.modal {
  z-index: 1050;
}

30. الطفو والمسح (Float & Clear)

التقنية الكلاسيكية لإزاحة العناصر يميناً ويساراً وجعل النصوص يلتفون حولها.

.float-left {
  float: left;
}

31. تجاوز المحتوى (Overflow)

التحكم بما يحدث عندما يكون محتوى الصندوق أكبر من أبعاده المحددة (ظهور تمرير أو إخفاء الزائد).

.scrollable {
  overflow: auto;
}

32. خطوط النصوص (Font-Family)

تحديد نوع الخط المستخدم وطبقات الاحتياط في حال عدم توفر الخط الأساسي.

body {
  font-family: "Segoe UI", Tahoma, sans-serif;
}

33. أحجام وأوزان الخطوط

التحكم بسماكة ونحافة الخطوط العريضة عبر خاصية الأوزان.

.bold-text {
  font-weight: 700;
  font-size: 18px;
}

34. تباعد النصوص والأسطر

ضبط مسافات الحروف وارتفاعات السطور لتسهيل القراءة المريحة.

p {
  line-height: 1.8;
  letter-spacing: 0.5px;
}

35. محاذاة واتجاه النصوص

توزيع النصوص يميناً، يساراً، توسيطاً، أو ضبط الحواف المتساوية.

.text-center {
  text-align: center;
}

36. تأثيرات النصوص الظلال

إضافة ظلال جمالية للنصوص البارزة عبر text-shadow.

h1 {
  text-shadow: 2px 2px 4px rgba(0,0,0,0.2);
}

37. خلفيات الألوان والصور

تضمين الألوان والخلفيات المصورة داخل الصناديق.

.bg {
  background-color: #fff;
  background-image: url('img.jpg');
}

38. تحجيم وتكرار الخلفيات

منع تكرار صورة الخلفية وضبط تغطيتها الكاملة للحاوية.

.hero-bg {
  background-repeat: no-repeat;
  background-size: cover;
}

39. التدرجات الخطية (Linear Gradient)

دمج لونين أو أكثر بتدرج هندسي سلس واتجاهي.

.hero {
  background: linear-gradient(135deg, #0b4f88, #1677c8);
}

40. التدرجات الدائرية (Radial Gradient)

صنع تدرجات لونية تبدأ من مركز الدائرة وتتوسع للأطراف.

.circle-grad {
  background: radial-gradient(circle, #fff, #d7e1eb);
}

41. الظلال (Box-Shadow)

إعطاء عمق وثلاثية أبعاد للبطاقات والصناديق.

.card {
  box-shadow: 0 8px 24px rgba(20,55,90,.09);
}

42. المرشحات البصرية (Filters)

تطبيق تأثيرات تشويش، تباعد ألوان، أو إضاءة على الصور.

.blurred {
  filter: blur(5px);
}

43. الشفافية (Opacity & RGBA)

التحكم بنسب الشفافية للعناصر الكاملة أو الألوان المنفصلة.

.transparent {
  opacity: 0.8;
}

44. مقدمة نظام Flexbox

النظام المرن لترتيب وتوزيع العناصر في اتجاه واحد بكفاءة عالية.

.flex-container {
  display: flex;
}

45. المحور الرئيسي والعرض في Flex

تحديد ما إذا كان توزيع العناصر أفقياً أم عمودياً.

.col-flex {
  flex-direction: column;
}

46. المحاذاة في الاتجاهين (Align & Justify)

توسيط وتوزيع العناصر داخل الحاوية المرنة بكل يسر.

.centered {
  justify-content: space-between;
  align-items: center;
}

47. التفاف العناصر (Flex-Wrap)

السماح للعناصر بالانتقال لسطر جديد عند ضيق مساحة الشاشة.

.wrap-box {
  flex-wrap: wrap;
}

48. خصائص العناصر المرنة (Grow, Shrink, Basis)

التحكم بنسب تمدد وانكماش العناصر المرنة داخل الحاوية.

.item {
  flex: 1 1 auto;
}

49. ترتيب العناصر (Order)

تغيير ترتيب ظهور العناصر بصرياً دون تعديل الكود المصدري HTML.

.first-item {
  order: -1;
}

50. مقدمة نظام الشبكات (CSS Grid)

النظام الأقوى لتصميم التخطيطات المعقدة ثنائية الأبعاد (صفوف وأعمدة).

.grid {
  display: grid;
}

51. تعريف الصفوف والأعمدة (Grid Template)

تخصيص قياسات الأعمدة والصفوف للشبكة بدقة.

.grid-cols {
  grid-template-columns: repeat(3, 1fr);
}

52. الفجوات بين الشبكات (Gap)

صنع مسافات فاصلة ومنتظمة بين خلايا الشبكة.

.grid {
  gap: 20px;
}

53. دمج الخلايا في Grid

جعل العنصر يعبر أكثر من عمود أو صف داخل الشبكة.

.span-col {
  grid-column: span 2;
}

54. التوزيع التلقائي (Auto-fit & Minmax)

إنشاء شبكات متجاوبة بالكامل تتكيف ذاتياً مع أبعاد الأجهزة.

.auto-grid {
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}

55. التصميم المتجاوب (Media Queries)

استهداف مقاسات شاشات معينة لتعديل مظهر الموقع وتخطيطه.

@media (max-width: 900px) {
  aside { transform: translateX(100%); }
}

56. نهج تصميم الموبايل أولاً (Mobile First)

استراتيجية كتابة التجاوب بدءاً من الشاشات الصغيرة صعوداً للشاشات الكبيرة عبر min-width.

57. الانتقالات السلسة (Transitions)

إعطاء نعومة وسلاسة عند تغير خصائص العنصر (مثل تأثيرات الأزرار).

.btn {
  transition: background-color 0.3s ease;
}

58. مدة وتوقيت الانتقالات (Timing Functions)

التحكم في سرعة التسارع والتباطؤ أثناء حدوث الانتقال البصري.

.box {
  transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
}

59. إطار الحركات (Keyframes Animations)

صنع حركات تفاعلية متقدمة ومتعددة المراحل عبر الإطارات المفتاحية.

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

60. تشغيل وإدارة الحركات

التحكم بعدد مرات التكرار، الاتجاه، وحالة إيقاف الحركة أو تشغيلها.

.animated {
  animation: fadeIn 0.5s ease infinite alternate;
}

61. التحويلات ثنائية الأبعاد (2D Transforms)

تدوير، تكبير، إزاحة، أو ميل العناصر على المستويين الأفقي والعمودي.

.box:hover {
  transform: scale(1.05) rotate(3deg);
}

62. التحويلات ثلاثية الأبعاد (3D Transforms)

صنع تأثيرات المنظور والعمق الثلاثي الأبعاد في واجهات الويب.

.card-3d {
  transform: perspective(1000px) rotateY(45deg);
}

63. المتغيرات في CSS (Custom Properties)

حفظ القيم المتكررة والألوان في الجذر لتسهيل إدارتها.

:root {
  --main-color: #1677c8;
}

64. نطاق المتغيرات (Scope)

الفرق بين المتغيرات المعرفة في الجذر ومتغيرات النطاق المحلي داخل الصناديق.

65. تصميم الوضع المظلم (Dark Mode)

تغيير ثيم الألوان بالكامل عبر تبديل قيم المتغيرات بحسب سمة البيانات.

[data-theme="dark"] {
  --bg: #0c1420;
  --card: #151f2c;
}

66. تنسيق الجداول (Tables)

إضافة التخطيطات، الحدود، والتداخل اللوني لصفوف وأعمدة الجداول.

tr:nth-child(even) {
  background-color: rgba(0,0,0,0.02);
}

67. تنسيق القوائم والروابط (Lists)

إزالة الرموز الافتراضية للقوائم وتنسيق الروابط لتلائم القوائم الجانبية والهيدر.

ul {
  list-style: none;
}

68. تنسيق النماذج وحقول الإدخال (Forms)

جعل حقول النص والأزرار عصرية، مريحة، وذات حدود متناسقة.

input {
  border: 1px solid var(--b);
  border-radius: 9px;
  padding: 10px;
}

69. حالات التركيز والتفاعل (Focus-within)

تنسيق الحاوية بالكامل عندما يقوم المستخدم بالنقر أو الكتابة داخل أي حقل داخلي.

.form-group:focus-within {
  border-color: var(--p);
}

70. المتغيرات الرياضية (Calc function)

إجراء عمليات حسابية ديناميكية للقياسات والأبعاد مباشرة داخل الأكواد.

.sidebar {
  width: calc(100% - 310px);
}

71. الدوال الشرطية (Clamp, Min, Max)

ضبط قياسات مرنة للخطوط والمسافات تتكيف بسلاسة تامة مع عرض الشاشة.

h1 {
  font-size: clamp(1.5rem, 2.5vw, 2.5rem);
}

72. العدادات التلقائية (Counters)

ترقيم العناوين والبنود تلقائياً عبر خصائص الـ CSS دون تدخل يدوي في HTML.

73. تخصيص شريط التمرير (Scrollbar)

تلوين وتصغير أشرطة التمرير لتتطابق تماماً مع الهوية البصرية للمنصة.

::-webkit-scrollbar {
  width: 8px;
}

74. تأثيرات دمج الألوان (Blend Modes)

صنع تداخلات بصرية مذهلة واحترافية بين الصور والخلفيات الملونة.

.blend {
  mix-blend-mode: multiply;
}

75. قص العناصر (Clip-Path)

عرض الصور والصناديق بأشكال هندسية مخصصة ومضلعات غير تقليدية.

.polygon {
  clip-path: polygon(0 0, 100% 0, 100% 80%, 0 100%);
}

76. اتجاه النصوص واللغات (RTL & LTR)

دعم اللغات المختلفة وتغيير اتجاه التخطيط والمحاذاة بسلاسة تامة.

html {
  direction: rtl;
}

77. تنسيق صفحة الطباعة (@media print)

إخفاء القوائم غير الضرورية والأزرار وتنسيق المحتوى الرئيسي حصرياً للطباعة الورقية.

@media print {
  header, aside, .actions { display: none !important; }
}

78. تحسين الأداء وسرعة التحميل

تنظيف الأكواد، ضغط الملفات، وتجنب الخصائص الثقيلة التي تبطئ تحميل وتصفح الصفحة.

79. أخطاء شائعة في كتابة الكود

تجنب الإفراط في استخدام !important وفوضى تداخل الفئات البرمجية.

80. تنظيم وترتيب ملفات CSS

طرق تقسيم الملفات الكبيرة إلى أجزاء ونظام الهيكلة لتسهيل الصيانة والتطوير.

81. مشروع عملي: تصميم بطاقات منتجات

تطبيق عملي لتنسيق بطاقات عرض ديناميكية متطورة مع تأثيرات المرور بالفأرة.

82. مشروع عملي: شريط تنقل متجاوب (Navbar)

تصميم هيدر متكامل مع قائمة جانبية متجاوبة للشاشات المصغرة.

83. مشروع عملي: معرض صور شبكي

بناء معرض صور متناسق باستخدام تقنيات CSS Grid المتقدمة.

84. مشروع عملي: لوحة تحكم متكاملة (Dashboard)

تصميم الواجهات الإدارية الاحترافية والجانبية للأنظمة الكبرى.

85. مشروع عملي: نموذج تسجيل الدخول

بناء فورم أنيق ومرن يدعم الوضعين المظلم والفاتح بمتغيرات النظام.

86. بناء نظام ثيمات متقدم

إدارة تعدد الثيمات والألوان للمنصات الرقمية باستخدام الخصائص الديناميكية المتطورة.

87. أفضل الممارسات البرمجية في CSS

معايير كتابة أكواد نظيفة وقابلة للتطوير والصيانة طويلة الأمد (Clean Code Principles).

88. المرجع السريع لأهم الخصائص

خلاصة شاملة وسريعة لأهم أوامر وخصائص الـ CSS الأساسية والمتقدمة للرجوع إليها فورياً.

/* خلاصة الختام لأهم المحددات والخصائص */
.quick-reference { display: grid; gap: 1rem; }
