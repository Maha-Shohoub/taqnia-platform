دليل JavaScript الشامل والمفصل

دليلك الهندسي المتكامل: من التدريب العملي إلى التطبيق الواقعي.

إعداد الكاتبة والمهندسة: مها شهوب

01. مقدمة في JavaScript

لغة الجافاسكريبت هي لغة البرمجة الأساسية المسؤولة عن إضافة التفاعل، الديناميكية، والمنطق البرمجي لصفحات الويب.

مثال عملي
// فحص البيئة البرمجية الأساسية
console.log("تشغيل محرك جافاسكريبت بنجاح");

02. طرق تضمين الجافاسكريبت

يمكن تضمين السكريبتات عبر وسم script مباشرة أو استدعاء ملف خارجي بصيغة .js لتحسين التنظيم.

مثال عملي
<script src="script.js" defer></script>

03. إخراج البيانات والطباعة

استخدام كونسول المتصفح للتصحيح أو إظهار رسائل منبثقة للمستخدم عبر الأوامر الأساسية.

مثال عملي
console.log("مرحباً بكم في آفاق المعرفة التقنية");

04. التعليقات وتوثيق الأكواد

كتابة الملاحظات وشرح الأجزاء البرمجية لتسهيل القراءة والصيانة المستقبليّة.

مثال عملي
// تعليق في سطر واحد
/* تعليق متعدد الأسطر لتوضيح النظام */

05. المتغيرات بـ let و const

حجز مساحات تخزين في الذاكرة للقيم المتغيرة (let) والثابتة (const) الحديثة.

مثال عملي
const appName = "آفاق المعرفة التقنية";
let visitorCount = 120;

06. أنواع البيانات الأساسية

التعرف على أنواع البيانات البرمجية مثل النصوص، الأرقام، القيم المنطقية، والقيم الفارغة.

مثال عملي
let isPublished = true;
let score = 98.5;

07. العمليات الحسابية

تنفيذ العمليات الرياضية كالجمع، الطرح، الضرب، القسمة، وباقي القسمة.

مثال عملي
let total = 10 + 5 * 2;

08. معاملات التخصيص والمقارنة

تحديث قيم المتغيرات ومقارنة القيم ببعضها البعض (مثل أكبر من أو يساوي).

مثال عملي
let x = 10;
x += 5; // تصبح 15

09. المعاملات المنطقية (AND, OR, NOT)

ربط الشروط البرمجية المتعددة باستخدام الرموز المنطقية && و || و !.

مثال عملي
if (isAdmin && isLoggedIn) {
  console.log("مرحباً بك في لوحة التحكم");
}

10. نصوص الـ Strings ومعالجتها

التعامل مع السلاسل النصية ودمجها وطول النص البرمجي.

مثال عملي
let title = "مها شهوب";
console.log(title.length);

11. قوالب النصوص Template Literals

استخدام العلامة العكسية (`) لدمج المتغيرات داخل النصوص بطريقة نظيفة وسهلة.

مثال عملي
let greeting = `مرحباً بكِ يا مهندسة ${title}`;

12. الطرق الشائعة للنصوص

البحث، الاستبدال، وتقطيع النصوص عبر الدوال الجاهزة.

مثال عملي
let text = "JavaScript Programming";
let upper = text.toUpperCase();

13. الأرقام والعمليات الرياضية Math

استخدام كائن الرياضيات المدمج للتقريب، الجذور، والقيم العشوائية.

مثال عملي
let rnd = Math.floor(Math.random() * 10) + 1;

14. الجمل الشرطية If / Else

توجيه مسار البرنامج لتنفيذ أكواد مختلفة بناءً على تحقق الشروط.

مثال عملي
if (score >= 50) {
  console.log("ناجح");
} else {
  console.log("راسب");
}

15. جملة الاختيار Switch

اختبار متغير ضد عدة حالات محتملة بشكل منظم بديل لتعدد جمل if.

مثال عملي
switch(day) {
  case 1: console.log("السبت"); break;
  default: console.log("يوم عادي");
}

16. المعامل الثلاثي Ternary

اختصار الجمل الشرطية البسيطة في سطر برمجي واحد وموجز.

مثال عملي
let status = (age >= 18) ? "بالغ" : "قاصر";

17. حلقة التكرار For

تكرار تنفيذ كتلة برمجية لعدد محدد مسبقاً من المرات.

مثال عملي
for(let i = 0; i < 5; i++) {
  console.log(i);
}

18. حلقة التكرار While و Do...While

التكرار استناداً إلى تحقق شرط معين طالما أنه بقيمته الصحيحة.

مثال عملي
let i = 0;
while(i < 3) { i++; }

19. التحكم بالتكرار Break و Continue

إيقاف حلقة التكرار نهائياً أو تخطي التكرار الحالي.

مثال عملي
if(i === 2) continue;

20. الدوال الأساسية Functions

تغليف الأكواد في كتل برمجية قابلة لإعادة الاستخدام عند النداء.

مثال عملي
function calculateSum(a, b) {
  return a + b;
}

21. التعبيرات ونطاق الدوال (Function Expressions)

إسناد الدوال إلى متغيرات برمجية للاستفادة منها بسلاسة وتحديد سلوكها التنفيذي.

مثال عملي
const greet = function(name) { return `أهلاً ${name}`; };

22. الدوال السهمية Arrow Functions

الصيغة الحديثة والمختصرة لكتابة الدوال في جافاسكريبت ES6.

مثال عملي
const multiply = (a, b) => a * b;

23. نطاق المتغيرات Scope

فهم النطاق المحلي (Local) والنطاق العام (Global) لمدى رؤية المتغيرات ومنع تداخلها.

مثال عملي
let globalVar = "عام";
function test() { let localVar = "محلي ضمن الدالة"; }

24. مقدمة المصفوفات Arrays

تخزين قوائم متعددة من البيانات داخل متغير واحد مرن.

مثال عملي
let techList = ["HTML", "CSS", "JavaScript"];

25. أساليب المصفوفات الأساسية

إضافة وإزالة العناصر من بداية ونهاية المصفوفات (push, pop, shift).

مثال عملي
techList.push("Python");
techList.pop();

26. البحث في المصفوفات

معرفة مواقع العناصر والبحث عنها باستخدام indexOf و includes.

مثال عملي
let hasCss = techList.includes("CSS");

27. تكرار المصفوفات Loops & Methods

المرور على عناصر المصفوفة عن طريق forEach والتكرار الحديث.

مثال عملي
techList.forEach(item => console.log(item));

28. دوال Map, Filter, Reduce

الأساليب الاحترافية لتحويل، تصفية، وتجميع بيانات المصفوفات.

مثال عملي
let nums = [1, 2, 3];
let doubled = nums.map(n => n * 2);

29. الكائنات Objects الأساسية

تخزين البيانات في شكل أزواج من المفاتيح والقيم (Key-Value).

مثال عملي
const user = { name: "مها", role: "مهندسة برمجيات" };

30. خصائص الكائنات وطرقها

الوصول إلى خصائص الكائن وتحديثها وإضافة دوال داخلية له.

مثال عملي
user.city = "طرابلس";
console.log(user.name);

31. الكائن المتسلسل This

فهم دلالة الكلمة المفتاحية this للإشارة إلى الكائن الحالي وقت تنفيذ السياق.

مثال عملي
const person = {
  name: "مها",
  sayHello() { return `أهلاً أنا ${this.name}`; }
};

32. كائن التاريخ والوقت Date

جلب التواريخ الحالية، الساعات، الدقائق، والتلاعب بالأزمنة.

مثال عملي
const now = new Date();
console.log(now.getFullYear());

33. توليد الأرقام العشوائية Random

صنع أنظمة خوارزمية لتوليد أرقام واختيارات عشوائية دقيقة.

مثال عملي
let randomNum = Math.floor(Math.random() * 100);

34. مقدمة DOM الأساسية

فهم نموذج كائنات المستند وكيفية ربط الجافاسكريبت بعناصر الـ HTML كشجرة عقد (Nodes).

مثال عملي
// هيكل شجرة المستند الافتراضي
const domRoot = document.documentElement;
console.log(domRoot.nodeName);

35. استهداف العناصر بـ DOM

اختيار العناصر عبر الأقسام، الـ IDs، والفئات بـ querySelector.

مثال عملي
const header = document.querySelector("header");

36. تعديل محتوى العناصر

تغيير النصوص والعناصر الداخلية ديناميكياً عبر innerText و innerHTML.

مثال عملي
document.getElementById("title").innerText = "دليل الجافاسكريبت الشامل";

37. تعديل الخصائص والتنسيقات

تغيير خصائص CSS، السمات، وإضافة كلاسات التصميم برمجياً.

مثال عملي
box.style.backgroundColor = "#1677c8";
box.classList.add("active");

38. إنشاء وحذف عناصر الـ DOM

صنع عناصر HTML جديدة وإضافتها للصفحة أو حذفها عند الحاجة.

مثال عملي
let p = document.createElement("p");
p.innerText = "عنصر جديد";
document.body.appendChild(p);

39. معالجة الأحداث Event Listeners

الاستماع لتفاعل المستخدم مثل النقر، الكتابة، والمرور بالفأرة.

مثال عملي
btn.addEventListener("click", () => {
  console.log("تم النقر على الزر");
});

40. أنواع الأحداث وتفاعل المستخدم

التعرف على أحداث التحميل (load)، التمرير (scroll)، وتغيير الحقول.

مثال عملي
window.addEventListener("scroll", () => {
  // رصد إحداثيات التمرير الديناميكي
});

41. انتشار الأحداث Bubbling & Capturing

فهم كيفية انتقال وتصاعد الأحداث عبر العناصر المتداخلة صعوداً من الابن إلى الأب.

مثال عملي
// إيقاف انتشار الحدث لضمان عدم تداخله
e.stopPropagation();

42. كائن الحدث Event Object

استخراج معلومات دقيقة عن الحدث الواقع مثل العنصر المُستهدف والإحداثيات.

مثال عملي
btn.addEventListener("click", (e) => {
  console.log("هدف الحدث:", e.target);
});

43. تفويض الأحداث Event Delegation

ربط الحدث بالعنصر الأب لإدارة الأحداث للعناصر الابنة الحالية والمستقبلية بكفاءة.

مثال عملي
document.body.addEventListener("click", (e) => {
  if(e.target.matches(".btn-item")) { /* تنفيذ الإجراء */ }
});

44. التخزين المحلي LocalStorage

حفظ البيانات في متصفح المستخدم لفترات طويلة لا تُمحى بإغلاق المتصفح.

مثال عملي
localStorage.setItem("theme", "dark");
let currentTheme = localStorage.getItem("theme");

45. التخزين المؤقت SessionStorage

حفظ البيانات مؤقتاً طوال فترة فتح جلسة التبويب الحالية فقط.

مثال عملي
sessionStorage.setItem("userSession", "active");

46. معالجة الأخطاء Try / Catch

التعامل مع الأخطاء البرمجية المتوقعة لمنع انهيار وتشوه التطبيق.

مثال عملي
try {
  // كود قد يحتمل خطأ تشغيلي
} catch (error) {
  console.log("تمت معالجة الخطأ:", error.message);
}

47. البرمجة غير المتزامنة Asynchronous

فهم عمل جافاسكريبت أحادية الخيط (Single-threaded) وكيفية التعامل مع المهام المجدولة.

مثال عملي
// نموذج طابور المهام وتأخير التنفيذ
setTimeout(() => console.log("مهمة غير متزامنة"), 1000);

48. الوعود Promises

هيكل برمجي لتمثيل نجاح أو فشل العمليات المستقبلية والشبكية.

مثال عملي
const myPromise = new Promise((resolve, reject) => {
  let success = true;
  if(success) resolve("تمت العملية بنجاح");
  else reject("فشلت العملية");
});

49. استخدام Async / Await

الطريقة الحديثة والأكثر نظافة للتعامل مع الوعود والعمليات غير المتزامنة بشكل متسلسل.

مثال عملي
async function fetchData() {
  let response = await fetch('api/data');
  let data = await response.json();
}

50. جلب البيانات Fetch API

التواصل مع الخوادم الخارجية وسحب البيانات وتحديث واجهات الويب.

مثال عملي
fetch('https://api.github.com')
  .then(res => res.json())
  .then(data => console.log(data));

51. التعامل مع صيغة JSON

تحويل الكائنات البرمجية إلى نصوص JSON والعكس لتبادل البيانات مع الخوادم.

مثال عملي
let jsonString = JSON.stringify(user);
let parsedObj = JSON.parse(jsonString);

52. البرمجة كائنية التوجه OOP

بناء البرمجيات باستخدام مفهوم الكائنات والفئات الهندسية وتغليف البيانات.

مثال عملي
// مبدأ تغليف البيانات وهندسة الكائنات
const AppConfig = { version: "1.0.0", debug: false };

53. الأصناف Classes والوراثة

كتابة الأصناف الحديثة وتوريث الخصائص بين الكائنات لتنظيم الأكواد.

مثال عملي
class Book {
  constructor(title) { this.title = title; }
}

54. الدوال البناءة Constructors

تهيئة الكائنات فور إنشائها عبر دالة البناء الأساسية وإسناد الخصائص الأولية.

مثال عملي
function SystemUser(name) {
  this.name = name;
  this.active = true;
}

55. النماذج الأولية Prototypes

نظام الوراثة الكلاسيكي الخفي والمبني عليه لغة جافاسكريبت لمشاركة الخصائص والدوال.

مثال عملي
SystemUser.prototype.getRole = function() { return "مستخدم النظام"; };

56. التفكيك Destructuring

استخراج القيم من المصفوفات والكائنات بسهولة في متغيرات مستقلة ونظيفة.

مثال عملي
const { name, role } = user;

57. معاملات الانتشار Spread & Rest

تجميع وفك عناصر المصفوفات والكائنات باستخدام النقاط الثلاث (...).

مثال عملي
let combined = [...techList, "Node.js"];

58. التعبيرات النمطية RegEx

البحث والتحقق من تطابق الأنماط النصية (مثل فحص الإيميلات وكلمات المرور).

مثال عملي
let emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

59. وحدة النظام Modules (Import/Export)

تقسيم الأكواد إلى ملفات مستقلة واستيراد وتصدير الدوال والمتغيرات.

مثال عملي
export function showMsg() { /* ... */ }
import { showMsg } from './module.js';

60. مؤقتات التمهيد Timeout & Interval

تنفيذ الأكواد بعد فترة زمنية محددة أو بشكل تكراري منتظم.

مثال عملي
setTimeout(() => { console.log("تم الانتظار"); }, 2000);

61. التعامل مع النماذج Form Validation

فحص وتدقيق مدخلات المستخدم قبل إرسالها إلى الخادم ومنع الإدخالات الخاطئة.

مثال عملي
function validateInput(val) {
  return val.trim().length > 3;
}

62. خريطة البيانات Map & Set

هياكل بيانات حديثة لتخزين المفاتيح والقيم الفريدة بكفاءة عالية.

مثال عملي
let uniqueSet = new Set([1, 2, 2, 3]); // تمنع التكرار

63. الخصائص الخاصة WeakMap & WeakSet

إدارة الذاكرة بذكاء عبر تخزين مراجع ضعيفة للكائنات لتجنب تسريب الذاكرة (Memory Leaks).

مثال عملي
const weakCache = new WeakMap();

64. العمليات الثنائية Bitwise Operators

التعامل مع البتات والأرقام الثنائية على مستوى الذاكرة السفلي للعمليات الرياضية السريعة.

مثال عملي
