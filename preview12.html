دليل PHP الشامل والمفصل للأكواد

المرجع الهندسي المتكامل لتطوير الويب من جهة الخادم، مزود بالأمثلة التطبيقية والشروح لكل درس من الـ 88 درساً.

إعداد الكاتبة والمهندسة: مها شهوب

01. مقدمة في لغة PHP

لغة PHP هي لغة برمجة نصية تُنفذ على الخادم (Server-side) وتُستخدم لبناء وتطوير تطبيقات الويب الديناميكية.

<?php
// التحقق من إصدار لغة PHP المشغل للخادم
echo "إصدار PHP الحالي: " . PHP_VERSION;
?>

02. تركيب ووسوم PHP الأساسية

كيفية كتابة الوسوم القياسية والقصيرة لدمج أكواد PHP داخل صفحات HTML بأمان.

<?php
echo "<h3>مرحباً بكم في منصة آفاق المعرفة التقنية</h3>";
?>

03. التعليقات والتوثيق

كتابة الملاحظات وشرح الأكواد البرمجية لتسهيل الصيانة وقراءة الشفرات الهندسية.

<?php
// تعليق أحادي السطر
# تعليق بديل
/* تعليق متعدد الأسطر 
   لتوثيق المكونات الكبرى */
?>

04. إخراج البيانات echo و print

استخدام الأوامر الأساسية لعرض النصوص والبيانات وإرسالها إلى المتصفح.

<?php
echo "مها شهوب", " - ", "سلسلة أساسيات التقنية";
print("<br>تم الطباعة بنجاح");
?>

05. المتغيرات وثوابت define

تخزين البيانات في متغيرات تبدأ بعلامة الدولار ($) وتعريف الثابتة عبر define أو const.

<?php
$author = "مها شهوب";
define("SITE_NAME", "آفاق المعرفة التقنية");
echo SITE_NAME . " بواسطة " . $author;
?>

06. أنواع البيانات Data Types

التعرف على أنواع البيانات البرمجية مثل النصوص، الأرقام الصحيحة والعائمة، والقيم المنطقية.

<?php
$string = "نص برمجي";
$intVal = 2026;
$floatVal = 99.9;
$isActive = true;
var_dump($isActive);
?>

07. العمليات الحسابية والرياضية

إجراء العمليات الحسابية الأساسية كالجمع، الطرح، الضرب، القسمة، وباقي القسمة.

<?php
$x = 10;
$y = 3;
echo $x % $y; // باقي القسمة = 1
?>

08. معاملات التخصيص والمقارنة

تحديث قيم المتغيرات واختبار مطابقة القيم والأنواع عبر (===).

<?php
$score = 80;
$score += 20; // تصبح 100
var_dump(100 === "100"); // خطأ لأن النوع مختلف
?>

09. المعاملات المنطقية

ربط الشروط البرمجية المتعددة باستخدام and, or, &&, ||, !.

<?php
$isAdmin = true;
$isLoggedIn = true;
if ($isAdmin && $isLoggedIn) {
    echo "مرحباً بك في لوحة الإدارة";
}
?>

10. معالجة النصوص Strings

دمج النصوص باستخدام النقطة (.) وقراءة طول السلسلة النصية عبر strlen.

<?php
$name = "مها شهوب";
echo "طول النص: " . mb_strlen($name, 'UTF-8');
?>

11. العمليات المتقدمة على النصوص

البحث، الاستبدال، وتقطيع النصوص عبر دوال مثل str_replace و strpos.

<?php
$text = "مرحباً بك في عالم البرمجة";
echo str_replace("البرمجة", "تطوير الويب", $text);
?>

12. الثوابت السحرية Magic Constants

استخدام الثوابت الجاهزة التي يتغير قُيمها حسب مكان استخدامها في الكود مثل __FILE__.

<?php
echo "مسار الملف الحالي: " . __FILE__;
?>

13. الجمل الشرطية If / Elseif / Else

توجيه مسار التنفيذ البرمجي بناءً على تحقق الشروط المنطقية.

<?php
$grade = 85;
if ($grade >= 90) {
    echo "امتياز";
} elseif ($grade >= 75) {
    echo "جيد جداً";
} else {
    echo "ناجح";
}
?>

14. جملة الاختيار Switch

مقارنة متغير محدد مع عدة حالات محتملة بشكل منظم وواضح.

<?php
$role = "admin";
switch ($role) {
    case "admin": echo "صلاحيات كاملة"; break;
    case "user": echo "صلاحيات محدودة"; break;
    default: echo "زائر";
}
?>

15. المعامل الثلاثي وتحديد النل

اختصار الشروط السريعة واستخدام معامل الدمج Null Coalescing (??).

<?php
$username = $_GET['user'] ?? "زائر مجهول";
echo $username;
?>

16. حلقة التكرار For

تكرار تنفيذ كتلة برمجية لعدد محدد ومعروف من المرات.

<?php
for ($i = 1; $i <= 5; $i++) {
    echo "الرقم: $i <br>";
}
?>

17. حلقة التكرار While و Do...While

التكرار استناداً إلى بقاء الشرط صحيحاً حتى يتم استيفاء القاعدة.

<?php
$counter = 1;
while ($counter <= 3) {
    echo "التكرار رقم: $counter
";
    $counter++;
}
?>

18. حلقة التكرار Foreach

الحلقة المخصصة للمرور على عناصر المصفوفات بسهولة فائقة.

<?php
$techs = ["HTML", "CSS", "JS", "PHP"];
foreach ($techs as $tech) {
    echo "- $tech <br>";
}
?>

19. التحكم بالتكرار Break و Continue

إيقاف حلقة التكرار نهائياً أو تجاوز دورة معينة.

<?php
for ($i = 1; $i <= 5; $i++) {
    if ($i == 3) continue;
    echo "$i ";
}
?>

20. الدوال الأساسية Functions

تجميع الأكواد المتكررة في دوال قابلة لإعادة الاستخدام والنداء.

<?php
function welcomeUser($name) {
    return "أهلاً بك يا $name في المنصة";
}
echo welcomeUser("مها");
?>

22. تمرير الوسائط بالمرجع والقيمة

تعديل قيمة المتغير الأصلي داخل الدالة عبر استخدام علامة العطف (&).

<?php
function addFive(&$num) {
    $num += 5;
}
$val = 10;
addFive($val);
echo $val; // تصبح 15
?>

23. نطاق المتغيرات Global & Local

فهم مدى رؤية المتغيرات المحلية داخل الدوال والعامة على مستوى الملف.

<?php
$x = 10;
function testScope() {
    global $x;
    echo $x;
}
testScope();
?>

24. مقدمة المصفوفات Indexed Arrays

تخزين عدة قيم برمجية مرتبة برقم تسلسلي يبدأ من الصفر.

<?php
$books = array("كتاب C++", "كتاب جافاسكريبت", "كتاب PHP");
echo $books[0];
?>

25. المصفوفات الترابطية Associative

استخدام مفاتيح نصية مخصصة بدلاً من الأرقام للوصول إلى القيم.

<?php
$authorInfo = ["name" => "مها شهوب", "role" => "مهندسة برمجيات"];
echo $authorInfo["name"];
?>

26. المصفوفات متعددة الأبعاد Multi-dimensional

مصفوفات تحوي داخلها مصفوفات أخرى لتنظيم البيانات المركبة والجداول.

<?php
$matrix = [
    [1, 2, 3],
    [4, 5, 6]
];
echo $matrix[0][1]; // النتيجة 2
?>

27. دوال ترتيب ومعالجة المصفوفات

ترتيب العناصر تصاعدياً وتنازلياً عبر sort و rsort ودوال الفحص.

<?php
$nums = [5, 2, 9, 1];
sort($nums);
print_r($nums);
?>

28. دوال Map, Filter و Reduce

الأساليب الاحترافية للتعامل مع المصفوفات وتحويل بياناتها برمجياً.

<?php
$numbers = [1, 2, 3, 4];
$squared = array_map(fn($n) => $n * $n, $numbers);
print_r($squared);
?>

29. النماذج وإرسال البيانات GET

استقبال البيانات المُرسلة عبر الرابط وظهورها في مصفوفة $_GET.

<?php
// رابط مثل: index.php?search=php
$search = $_GET['search'] ?? '';
echo "كلمة البحث: " . htmlspecialchars($search);
?>

30. النماذج وإرسال البيانات POST

استقبال بيانات النماذج الآمنة والسرية عبر مصفوفة $_POST.

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST['username'] ?? '';
    echo "مرحباً: " . htmlspecialchars($username);
}
?>

31. التحقق من المدخلات والفلاتر

استخدام مرشحات الفحص filter_var للتحقق من صحة الإيميلات والروابط.

<?php
$email = "maha@example.com";
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "البريد الإلكتروني صحيح";
}
?>

32. التعامل مع الملفات المرفوعة Uploads

إدارة استقبال الملفات والصور عبر مصفوفة $_FILES وتخزينها بأمان في الخادم.

<?php
if (isset($_FILES['image'])) {
    $fileTmp = $_FILES['image']['tmp_name'];
    move_uploaded_file($fileTmp, "uploads/" . $_FILES['image']['name']);
}
?>

33. ملفات الكوكيز Cookies

حفظ وتخزين البيانات الصغيرة في متصفح المستخدم لفترة زمنية محددة.

<?php
setcookie("username", "مها", time() + 86400, "/");
echo $_COOKIE['username'] ?? 'غير موجود';
?>

34. الجلسات Sessions

حفظ بيانات المستخدم على الخادم مؤقتاً أثناء تصفحه للموقع عبر session_start.

<?php
session_start();
$_SESSION['auth'] = true;
echo $_SESSION['auth'] ? "مفعلة" : "معطلة";
?>

35. تضمين الملفات include و require

تقسيم التصميم إلى أجزاء (مثل الهدر والفوتر) واستدعائها لتجنب تكرار الكود.

<?php
// استدعاء ملف القالب الأساسي
include 'header.php';
?>

36. معالجة التواريخ والأوقات Date/Time

ضبط النطاق الزمني وجلب التواريخ الحالية ومنسقاتها عبر دالة date.

<?php
date_default_timezone_set('Africa/Tripoli');
echo "تاريخ اليوم: " . date("Y-m-d H:i:s");
?>

37. معالجة الأخطاء الاستثناءات Try/Catch

التقاط الأخطاء وتشغيل آليات حماية لمنع توقف التطبيق المعماري.

<?php
try {
    throw new Exception("خطأ في الاتصال بالخدمة");
} catch (Exception $e) {
    echo "تم رصد الخطأ: " . $e->getMessage();
}
?>

38. الدوال مجهولة الاسم Closures

كتابة دوال بدون اسم وإسنادها لمتغيرات أو تمريرها كمعاملات.

<?php
$greet = function($name) {
    return "أهلاً $name";
};
echo $greet("مهندسة مها");
?>

39. الدوال السهمية Arrow Functions

الصيغة الحديثة والموجزة لكتابة الدوال المختصرة في PHP 7.4+.

<?php
$multiplier = fn($n) => $n * 10;
echo $multiplier(5); // 50
?>

40. التعامل مع الملفات fopen و fread

فتح وقراءة محتويات الملفات النصية الموجودة على الخادم.

<?php
$file = fopen("data.txt", "r");
if ($file) {
    echo fread($file, filesize("data.txt"));
    fclose($file);
}
?>

41. كتابة وتعديل الملفات file_put_contents

الطريقة المختصرة والسريعة لكتابة وحفظ النصوص داخل الملفات.

<?php
file_put_contents("log.txt", "تسجيل دخول جديد بالنظام\n", FILE_APPEND);
?>

42. فحص حالة الملفات والمجلدات

التحقق من وجود الملفات وصلاحياتها وحجمها عبر file_exists.

<?php
if (file_exists("config.php")) {
    echo "ملف الإعدادات موجود ومتاحة";
}
?>

43. مقدمة قواعد البيانات MySQLi

الاتصال بقواعد بيانات MySQL باستخدام مكتبة MySQLi الإجرائية أو الكائنية.

<?php
$conn = new mysqli("localhost", "root", "", "my_db");
if ($conn->connect_error) {
    die("فشل الاتصال: " . $conn->connect_error);
}
?>

44. الاتصال بقاعدة البيانات عبر PDO

استخدام كائن PDO الموحد والمرن للاتصال بمختلف أنواع قواعد البيانات.

<?php
try {
    $pdo = new PDO("mysql:host=localhost;dbname=my_db", "root", "");
    echo "تم الاتصال بنجاح عبر PDO";
} catch (PDOException $e) {
    echo "خطأ: " . $e->getMessage();
}
?>

45. تنفيذ الاستعلامات بأمان Prepared Statements

حماية قاعدة البيانات من الاختراق واستخدام الاستعلامات المُجهزة (Prepared Statements).

<?php
$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");
$stmt->execute([$email]);
$user = $stmt->fetch();
?>

46. إدخال وجلب البيانات من القاعدة

كتابة أوامر الإدخال (INSERT) وجلب النتائج برمجياً عبر الحلقات.

<?php
$stmt = $pdo->prepare("INSERT INTO posts (title) VALUES (?)");
$stmt->execute(["دليل PHP الشامل"]);
?>

47. تحديث وحذف البيانات SQL

إدارة عمليات التعديل (UPDATE) والحذف (DELETE) لسجلات الجداول.

<?php
$pdo->query("UPDATE settings SET value = 'active' WHERE id = 1");
?>

48. البرمجة كائنية التوجه OOP الأساسية

بناء البرمجيات باستخدام مفهوم الكائنات والأصناف لتنظيم المشاريع الكبرى.

<?php
class SystemApp {
    public $name = "آفاق المعرفة التقنية";
}
$app = new SystemApp();
echo $app->name;
?>

49. الأصناف Classes والخصائص Properties

تعريف مكونات الأصناف البرمجية وإسناد الخصائص والأساليب المرتبطة بها.

<?php
class UserProfile {
    public $username;
    public function getProfile() { return $this->username; }
}
?>

50. دوال البناء والهدم Construct & Destruct

تهيئة الخصائص تلقائياً فور إنشاء الكائن باستخدام دالة البناء __construct.

<?php
class DatabaseManager {
    public function __construct() {
        echo "تم تهيئة الاتصال";
    }
}
$db = new DatabaseManager();
?>

51. الوراثة Inheritance

توريث الخصائص والدوال من صنف أساسي (Parent) إلى صنف فرعي (Child).

<?php
class Person { public $name; }
class Admin extends Person { public $level = 1; }
?>

52. الوصول العام والخاص Public/Private/Protected

حماية وتغليف البيانات داخل الأصناف وتحديد صلاحيات الرؤية.

<?php
class Account {
    private $password = "secret123";
    public function getPass() { return $this->password; }
}
?>

53. الخصائص والدوال الساكنة Static

استدعاء الخصائص والدوال مباشرة دون الحاجة لإنشاء كائن من الصنف.

<?php
class MathUtil {
    public static function square($n) { return $n * $n; }
}
echo MathUtil::square(4); // 16
?>

54. الواجهات Interfaces

تحديد القوالب المعيارية والدوال الواجب تنفيذها في الأصناف الفرعية.

<?php
interface Logger {
    public function logMessage($msg);
}
?>

55. الأصناف المجردة Abstract Classes

بناء قوالب أساسية تحتوي على دوال معرفة وأخرى مجردة يجب توريثها.

<?php
abstract class BaseController {
    abstract public function render();
}
?>

56. السمات Traits لتجاوز قيود الوراثة

إعادة استخدام مجموعات من الدوال في عدة أصناف مختلفة بلا قيود الوراثة الأحادية.

<?php
trait LoggerTrait {
    public function log() { echo "تسجيل الأحداث"; }
}
?>

57. مساحات الأسماء Namespaces
