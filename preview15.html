دليل لغة البرمجة ++C الشامل

المرجع الهندسي المتكامل لتطوير البرمجيات الهيكلية والكائنية وتحسين الأداء باستخدام ++C.

01. مقدمة عن لغة ++C وتاريخها

تطوير لغة C بواسطة بيار ستروستروب في أوائل الثمانينيات لتشمل ميزات البرمجة كائنية التوجه مع الحفاظ على كفاءة الأداء.

// ++C System Initialization
#include <iostream>
using namespace std;

02. بنية الهيكل البرمجي ودالة Main

نقطة الانطلاق الأساسية لأي تطبيق ++C عبر دالة التنفيذ الرئيسية main.

int main() {
    cout << "مرحباً بك في عالم ++C" << endl;
    return 0;
}

04. المتغيرات وأنواع البيانات الأساسية

حجز مساحات الذاكرة لأنواع البيانات المختلفة مثل الصحيح (int)، الحقيقي (double)، والحرفي (char).

int age = 25;
double salary = 1200.50;
char grade = 'A';
bool isActive = true;

05. العمليات الحسابية والمنطقية

استخدام المعاملات الرياضية والمنطقية لمعالجة القيم والبيانات.

int sum = 10 + 20;
bool check = (sum > 15) && (isActive == true);

06. الجمل الشرطية (if, else, switch)

توجيه مسار التنفيذ بناءً على تحقق الشروط المنطقية المختلفة.

if (age >= 18) {
    cout << "مؤهل للعمل" << endl;
} else {
    cout << "غير مؤهل" << endl;
}

07. الحلقات التكرارية (for, while, do-while)

تكرار تنفيذ الأكواد البرمجية بكفاءة عالية وبأقل عدد من الأسطر.

for(int i = 0; i < 5; i++) {
    cout << "الخطوة: " << i << endl;
}

08. المصفوفات أحادية الأبعاد Arrays

تخزين مجموعة من العناصر المتجانسة تحت اسم متغير واحد وبفهرس يبدأ من الصفر.

int scores[3] = {90, 85, 88};
cout << scores[0];

09. المصفوفات ثنائية الأبعاد Multi-dimensional

تمثيل الجداول والصفوف والأعمدة هندسياً في الذاكرة.

int matrix[2][2] = {{1, 2}, {3, 4}};

10. المؤشرات Pointers والذاكرة

المتغيرات التي تحوي عناوين الذاكرة للمتغيرات الأخرى لرفع كفاءة التحكم بالنظام.

int x = 10;
int *ptr = &x;
cout << *ptr; // طباعة القيمة عبر المؤشر

11. المؤشرات المتقدمة والمرجع References

استخدام المراجع كبدائل آمنة للمؤشرات لتمرير المتغيرات بسهولة.

int original = 50;
int &ref = original;
ref = 100; // يتغير original ليصبح 100

12. الدوال Functions وتعريفها

تجزئة البرنامج إلى وحدات مستقلة قابلة لإعادة الاستخدام والصيانة.

int add(int a, int b) {
    return a + b;
}

13. تمرير المعاملات بالقيم والمراجع

الفرق بين تمرير نسخة المتغير وتمرير عنوانه الحقيقي لتعديل قيمته.

void increment(int &val) {
    val++;
}

14. التحميل الزائد للدوال Function Overloading

تعريف عدة دالات بنفس الاسم مع اختلاف أنواع أو عدد المعاملات.

int multiply(int a, int b) { return a * b; }
double multiply(double a, double b) { return a * b; }

15. النطاق Scope والذاكرة التلقائية والثابتة

إدارة عمر المتغيرات ومجالات رؤيتها داخل الدوال والكتل البرمجية.

void counter() {
    static int count = 0;
    count++;
}

16. البرمجة كائنية التوجه OOP ومفهوم الكلاسات

تصميم النماذج البرمجية التي تدمج البيانات والدوال المرتبطة بها معاً.

class Book {
public:
    string title;
    void display() { cout << title; }
};

17. المنشئ Constructor والمدمج Destructor

تهيئة الكائنات تلقائياً عند إنشائها وتدميرها بأمان لتحرير الذاكرة.

class Database {
public:
    Database() { /* تهيئة الاتصال */ }
    ~Database() { /* إغلاق الاتصال */ }
};

18. مبدأ التغليف Encapsulation ومحددات الوصول

حماية البيانات عبر تحديد الصلاحيات (public, private, protected).

class Account {
private:
    double balance;
public:
    void setBalance(double b) { balance = b; }
};

19. الوراثة Inheritance وأنواعها

نقل الخصائص والدوال من فئة أساسية (Base) إلى فئات مشتقة (Derived).

class Vehicle {};
class Car : public Vehicle {};

20. تعدد الأشكال Polymorphism والدوال الافتراضية

استخدام الدوال الافتراضية (virtual functions) لتنفيذ سلوك مختلف بناءً على نوع الكائن.

class Shape {
public:
    virtual void draw() { cout << "Drawing Shape"; }
};

21. الفئات المجردة Abstract Classes واجهات

فرض هيكل أساسي موحد للفئات المشتقة عبر الدوال الصفرية النقية.

class Interface {
public:
    virtual void execute() = 0; // دالة نقية مجردة
};

22. قوالب الدوال Function Templates

كتابة كود عام يدعم أنواع بيانات متعددة تلقائياً.

template <typename T>
T getMax(T a, T b) {
    return (a > b)? a : b;
}

23. قوالب الكلاسات Class Templates

إنشاء هياكل بيانات وكلاسات عامة تتعامل مع أي نوع بيانات.

template <class T>
class Box {
    T data;
};

24. إدارة الذاكرة الديناميكية (new / delete)

حجز وتحرير الذاكرة يدوياً أثناء تشغيل البرنامج لتوفير المرونة.

int *p = new int(10);
delete p; // تحرير الذاكرة لمنع التسريب

25. مؤشرات الذاكرة الذكية Smart Pointers

استخدام unique_ptr و shared_ptr لإدارة الذاكرة تلقائياً ومنع تسريبها.

#include <memory>
unique_ptr<int> sptr = make_unique<int>(20);

26. معالجة الاستثناءات (try, catch, throw)

التقاط الأخطاء وقت التشغيل ومعالجتها بسلاسة دون انهيار التطبيق.

try {
    throw "خطأ في النظام";
} catch (const char* msg) {
    cout << msg;
}

27. التعامل مع الملفات (Files I/O)

قراءة وكتابة البيانات في الملفات النصية والثنائية.

ofstream file("data.txt");
file << "مها شهوب - توثيق بيانات";
file.close();

28. مقدمة في مكتبة القوالب القياسية STL

استخدام الهياكل والخوارزميات الجاهزة عالية الأداء في ++C.

#include <vector>
#include <algorithm>

29. الحاويات المتسلسلة (Vector, List, Deque)

إدارة المجموعات المرنة ذات الحجم الديناميكي.

vector<int> vec = {1, 2, 3};
vec.push_back(4);

30. الحاويات الترابطية (Map, Set)

تخزين البيانات بنظام المفتاح والقيمة الفريدة المرتبطة.

map<string, int> ages;
ages["مها"] = 25;

31. الخوارزميات القياسية في STL

تطبيق عمليات الفرز، البحث، والمعالجة السريعة على الحاويات.

sort(vec.begin(), vec.end());

32. هياكل البيانات: القوائم المرتبطة Linked Lists

بناء العقد المرتبطة بروابط الذاكرة الديناميكية.

struct Node { int data; Node* next; };

33. هياكل البيانات: المكدس Stack والصف Queue

تنفيذ قواعد LIFO (المكدس) و FIFO (الصف) برمجياً.

#include <stack>
stack<int> s; s.push(10);

34. هياكل البيانات: الأشجار الثنائية Binary Trees

تنظيم البيانات هرمياً للبحث السريع والتنقل.

struct TreeNode { int val; TreeNode *left, *right; };

35. هياكل البيانات: خوارزميات البحث والفرز

36. التعبيرات السهمية واللامسمى Lambda Expressions

كتابة دوال سريعة ومجهولة الاسم ضمن الأسطر البرمجية.

auto sum = [](int a, int b) { return a + b; };

37. البرمجة المتزامنة Multithreading

تشغيل عدة خيوط معالجة بالتوازي لرفع أداء التطبيقات الضخمة.

#include <thread>
thread t([]{ cout << "خيوط المعالجة نشطة"; });
t.join();

تطبيق مفاهيم الكلاسات، الوراثة، وحاويات STL لإدارة المنتجات.
