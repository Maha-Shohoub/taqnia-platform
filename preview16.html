دليل لغة البرمجة C الشامل

المرجع الهندسي المتكامل لتطوير البرمجيات الأساسية، التحكم المباشر بالذاكرة، وهندسة النظم بكفاءة عالية.

إعداد الكاتبة والمهندسة: مها شهوب

01. مقدمة عن لغة C وتاريخها

تم تطوير لغة C بواسطة دينيس ريتشي في مختبرات بيل عام 1972 لتصميم نظام التشغيل يونكس، وتتميز بالسرعة والقدرة على التحكم المباشر بالعتاد.

// C Language Initialization
#include <stdio.h>

02. الهيكل العام للبرنامج ودالة Main

يبدأ تنفيذ أي برنامج مكتوب بلغة C حصرياً من الدالة الرئيسية main والتي تعيد قيمة صحيحة تدل على حالة الإنهاء.

int main() {
    printf("مرحباً بك في دليل لغة C\n");
    return 0;
}

03. أنواع البيانات الأساسية ومقاساتها

تشمل أنواع البيانات الصحيحة (int)، الحقيقية (float, double)، والحرفية (char) مع تباين مساحاتها التخزينية في الذاكرة.

int age = 30;
float temperature = 36.5;
double precise_val = 19.987654;
char grade = 'A';

04. المتغيرات والثوابت وقواعد التسمية

حجز أماكن في الذاكرة لتخزين القيم المتغيرة، أو استخدام الثوابت (const / #define) لمنع تعديل البيانات.

const int MAX_USERS = 100;
#define PI 3.14159

05. العمليات الحسابية ومعاملات الإسناد

تطبيق العمليات الرياضية الأربع الكبرى بالإضافة إلى باقي القسمة (%) ومعاملات الاختصار (++, --).

int x = 10, y = 3;
int sum = x + y;
int rem = x % y; // الباقي 1

06. المدخلات والمخرجات الأساسية (printf / scanf)

استخدام الدوال القياسية لطباعة النصوص وقراءة المدخلات من لوحة المفاتيح عبر محددات التنسيق (%d, %f, %s).

int num;
printf("أدخل رقماً: ");
scanf("%d", &num);
printf("الرقم المدخل: %d\n", num);

07. الجمل الشرطية (if, else if, else)

التحكم في مسار تنفيذ الأكواد بناءً على تقييم الشروط المنطقية.

int score = 85;
if (score >= 90) {
    printf("ممتاز\n");
} else if (score >= 75) {
    printf("جيد جداً\n");
} else {
    printf("مقبول\n");
}

08. جملة الاختيار المتعدد (switch)

تنفيذ مسارات مختلفة بناءً على قيمة متغيرة واحدة بكفاءة وتنظيم.

int day = 2;
switch(day) {
    case 1: printf("السبت"); break;
    case 2: printf("الأحد"); break;
    default: printf("يوم آخر");
}

09. الحلقات التكرارية (for loop)

تنفيذ مجموعة من التعليمات عدد محدد مسبقاً من المرات عبر التحكم بالعداد.

for(int i = 0; i < 5; i++) {
    printf("التكرار رقم: %d\n", i);
}

10. الحلقات التكرارية (while & do-while)

التكرار بناءً على تحقق شرط مستمر، مع ضمان تنفيذ الكود لمرة واحدة على الأقل في حلقة do-while.

int count = 3;
while(count > 0) {
    count--;
}

12. الدوال (Functions) وتعريفها

تقسيم البرنامج إلى وحدات برمجية مستقلة لتسهيل القراءة والصيانة وتجنب تكرار الكود.

int multiply(int a, int b) {
    return a * b;
}

13. تمرير المعاملات بالقيم

آلية تمرير النسخ للدوال بحيث لا تتأثر المتغيرات الأصلية خارج نطاق الدالة.

void modify(int x) {
    x = 50; // لا يؤثر على المتغير الأصلي في الخارج
}

14. نطاق المتغيرات المحلية والعامة (Scope)

الفرق بين المتغيرات المعرفة داخل الدوال (محليه) وتلك المعرفة في بداية الملف (عامة).

int global_var = 100; // متغير عام مرئي لجميع الدوال

15. المصفوفات أحادية الأبعاد (Arrays)

تخزين مجموعة متجانسة من العناصر في مواقع ذاكرة متتالية.

int numbers[5] = {10, 20, 30, 40, 50};
printf("%d", numbers[2]); // طباعة 30

16. المصفوفات ثنائية الأبعاد (Multi-dimensional)

تمثيل الجداول والصفوف والأعمدة مثل المصفوفات الرياضية.

int matrix[2][2] = {
    {1, 2},
    {3, 4}
};

17. النصوص (Strings) ومعالجة الحروف

تمثيل النصوص كمصفوفات من الحروف تنتهي بحرف الإلغاء (Null Terminator '\0').

char name[] = "مها شهوب";
printf("الاسم: %s\n", name);

18. مقدمة في المؤشرات (Pointers) وعناوين الذاكرة

المتغيرات التي تخزن عناوين الذاكرة للمتغيرات الأخرى، وتعتبر جوهر قوة لغة C.

int var = 25;
int *ptr = &var; // ptr يحمل عنوان var
printf("العنوان: %p القيمة: %d\n", ptr, *ptr);

19. المؤشرات والمصفوفات

الارتباط الوثيق بين اسم المصفوفة والمؤشر المؤدي لأول عنصر فيها.

int arr[3] = {5, 10, 15};
int *p = arr;
printf("%d", *(p + 1)); // طباعة العنصر الثاني 10

20. تمرير المؤشرات للدوال

تمكين الدوال من تعديل القيم الأصلية للمتغيرات عبر تمرير عناوينها في الذاكرة (Pass by Reference).

void updateValue(int *val) {
    *val = 500; // تعديل القيمة في العنوان الأصلي
}

21. تخصيص الذاكرة الديناميكية (malloc, calloc, free)

حجز المساحات في الذاكرة العشوائية أثناء تشغيل البرنامج وتحريرها يدوياً لمنع التسريب.

int *arr = (int*) malloc(10 * sizeof(int));
if (arr != NULL) {
    // استخدام الذاكرة المحجوزة
    free(arr); // تحرير الذاكرة
}

22. الهياكل (Structures) وتجميع البيانات

إنشاء أنواع بيانات مخصصة تجمع متغيرات ذات أنواع مختلفة تحت كيان واحد.

struct Book {
    char title[50];
    int pages;
};
struct Book b1 = {"أساسيات التقنية", 250};

23. الاتحادات (Unions) والتعدادات (Enums)

الاتحادات تشترك في نفس مساحة الذاكرة، بينما التعدادات تعطي أسماء واضحة للقيم العددية.

enum Status { SUCCESS = 0, FAILURE = 1 };
enum Status current = SUCCESS;

24. التعامل مع الملفات (File I/O: fopen, fread, fwrite)

فتح، قراءة، وكتابة البيانات في الملفات النصية والثنائية على القرص الصلب.

FILE *f = fopen("data.txt", "w");
fprintf(f, "توثيق بيانات النظام\n");
fclose(f);

25. الموجهات المسبقة للمترجم (Preprocessor Directives)

أوامر مثل #define و #include لمعالجة الكود قبل عملية الترجمة الفعلية.

#define SQUARE(x) ((x) * (x))
