دليل لغة ترميز البيانات (XML) الشامل

هندسة تخزين، تبادل، والتحقق من سلامة البيانات الهرمية من الجذور حتى الاحتراف؛ رؤية برمجية متكاملة لربط الأنظمة المتباينة.

01. مقدمة عن لغة XML وتاريخها

لغة ترميز قابلة للتوسعة (Extensible Markup Language) تم تطويرها بواسطة منظمة W3C عام 1998 لتسهيل تخزين ونقل البيانات الهرمية بين الأنظمة المختلفة باستقلالية تامة عن منصات التشغيل.

<?xml version="1.0" encoding="UTF-8"?>
<!-- مقدمة توثيقية أساسية لملفات XML القياسية -->

02. بنية وهيكل مستند XML الأساسي

يعتمد المستند على عنصر جذري واحد (Root Element) يضم تحته كافة العناصر الفرعية بترتيب هرمي دقيق ومتشعب.

<Library>
    <Book>أساسيات التقنية</Book>
</Library>

03. قواعد صياغة العناصر والعلامات (Tags)

تشترط لغة XML الحساسية لحالة الأحرف (Case-sensitive)، ضرورة إغلاق كافة العلامات المفتوحة، وتجنب تداخل الهياكل.

<Student>
    <Name>مها شهوب</Name>
&</Student>

04. خصائص العناصر Attributes واستخداماتها

تستخدم الخصائص لإرفاق بيانات وصفية إضافية بالعنصر (مثل المعرفات الفريدة والأنواع)، يفضل حصرها للبيانات غير الهرمية.

<Course id="CS101" level="Advanced">
    <Title>نظم قواعد البيانات</Title>
</Course>

05. التعليقات ومحارف الهروب (Entities)

استخدام الرموز الخاصة مثل &amp; و &lt; لتمثيل المحارف المحجوزة، وكتابة التعليقات التوثيقية بوضوح.

<!-- تعليق هندسي توثيقي -->
<Expression>A &lt; B &amp; C &gt; D</Expression>

06. هندسة البيانات الهرمية والعلاقات

تصميم الجذور والأفرع لتشكيل علاقات واضحة (أب - ابن - شقيق) تحاكي الكيانات الواقعية.

<Organization>
    <Department name="Engineering">
        <Employee>مهندسة مها&&Employee>
    </Department>
</Organization>

07. التحقق من صحة المستندات DTD

استخدام تعريف نوع المستند (Document Type Definition) لفرض هيكل وقواعد صارمة على محتوى الملفات.

<!ELEMENT Note (To, From, Body)>
<!ELEMENT To (#PCDATA)>

08. مخططات XML Schema (XSD) المتطورة

المعمارية الحديثة والأكثر قوة للتحقق من أنواع البيانات والهياكل باستخدام مستندات مكتوبة بلغة XML ذاتها.

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
    <xs:element name="Age" type="xs:integer"/>
&&/xs:schema>

09. أنواع البيانات والقيود في XSD

تحديد الأطوال، الأنماط النصية (Patterns)، النطاق الرقمي، والقيود الزمنية للقيم المدخلة.

<xs:element name="Score">
    <xs:simpleType>
        <xs:restriction base="xs:integer">
            <xs:minInclusive value="0"/>
            <xs:maxInclusive value="100"/>
        &&/xs:restriction>
    &&/xs:simpleType>
&&/xs:element>

10. استعلامات البيانات XPath الأساسية

لغة المسارات المستخدمة للتنقل عبر عناصر وخصائص مستند XML واستخراج البيانات المستهدفة بدقة.

// تحديد مسار العناصر الأساسية
/Library/Book/Title

11. مسارات البحث والتعبيرات في XPath

استخدام الفلاتر، الشرطات العقدية، والوظائف المتقدمة لتصفية النتائج البرمجية.

// استخراج الكتب التي يتجاوز سعرها قيمة محددة
//Book[Price > 50]

12. تحويل المستندات XSLT والأنماط

لغة تحويل مستندات XML إلى تنسيقات أخرى مثل HTML، أو نص عادي، أو مستندات XML بأشكال جديدة.

<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:template match="/">...</xsl:template>
&&/xsl:stylesheet>

آليات تحليل الملفات (DOM و SAX Parsers) في لغات البرمجة لاستخراج وتعديل محتويات العقد برمجياً.

14. استخدام XML في ملفات التعديل والإعدادات Config

الاعتماد الواسع على XML في ضبط إعدادات الاتصال، سلاسل قواعد البيانات، وصلاحيات الأنظمة.

<configuration>
    <add key="Server" value="localhost"/>
&&/configuration>

15. مقارنة هندسية بين XML و JSON

مقارنة شاملة من حيث الأداء، دعم التوثيق، التحقق الصارم عبر XSD، وحجم النقل على الشبكات.

-- XML: دعم قوي للتحقق والمخططات (XSD)
-- JSON: خفة الحجم وسهولة التوافق مع JavaScript

16. مشروع هندسي: نظام تخزين كتب مكتبة رقمية

تصميم ملف XML متكامل لهندسة بيانات الكتب، المؤلفين، الأسعار، وسنوات الإصدار.

<DigitalLibrary>
    <Book id="B01">
        <Title>هندسة قواعد البيانات</Title>
        <Author>مها شهوب&&Author>
        <Price currency="LYD">45.00&&Price>
    &&Book>
&&/DigitalLibrary>

17. مشروع هندسي: هيكل بيانات هيكلي لدرجات طلاب

بناء مستند XML يمثل بيانات الجامعة، الكليات، المقررات، وعلامات الطلاب الفصلية.

<University>
    <Student id="202601">
        <Name>طالب تقني&&Name>
        <Grade course="DBMS">95.5&&Grade>
    &&Student>
&&/University>

18. مشروع هندسي: سجل معاملات بنكية مؤرشفة

هندسة سجلات الحسابات البنكية لضمان التدقيق، الأختام الزمنية، ومتابعة الحركات المالية بدقة.

<BankTransactions>
    <Transaction type="Deposit" timestamp="2026-10-18T19:00:00">
        <AccountNo>100200300&&AccountNo>
        <Amount>1250.00&&Amount>
    &&Transaction>
&&/BankTransactions>
