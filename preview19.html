01. مقدمة عن مكتبة React وفلسفتها

مكتبة JavaScript مفتوحة المصدر تم تطويرها بواسطة Meta (Facebook) لبناء واجهات المستخدم الديناميكية بناءً على مفهوم المكونات المعزولة (Components) ونظام Virtual DOM لرفع الكفاءة والأداء.

// الفلسفة الأساسية: الواجهة عبارة عن دالة تعكس الحالة (UI = f(state))

02. إعداد البيئة وإنشاء مشروع جديد (Vite / Node)

استخدام أدوات البناء السريعة الحديثة مثل Vite لإنشاء بيئة عمل React متكاملة ومهيأة للتشغيل الفوري.

# أوامر إنشاء وتشغيل المشروع عبر موجه الأوامر
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev

03. هيكلية المشروع وملفات التكوين الأساسية

فهم مجلدات المشروع (src, public, node_modules) وملف نقطة الدخول الرئيسية main.jsx أو App.jsx.

// ربط التطبيق بمدخل المستند DOM الحقيقي
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'

ReactDOM.createRoot(document.getElementById('root')).render(<App />);

04. مقدمة في لغة JSX وبنية العناصر

صيغة برمجية تدمج JavaScript مع HTML لتمكين كتابة عناصر واجهة المستخدم بمرونة وسهولة فائقة.

const element = <h1 className="header">مرحباً بكم في أكاديمية آفاق المعرفة التقنية</h1>;

05. المكونات (Components) وإنشائها

تقسيم الواجهة إلى أجزاء مستقلة وقابلة لإعادة الاستخدام باستخدام الدوال البرمجية (Functional Components).

function WelcomeCard() {
    return <div><h3>مكون ترحيبي مخصص</h3></div>;
}
export default WelcomeCard;

06. تمرير البيانات عبر الخصائص (Props)

آلية تمرير البيانات من المكون الأب إلى المكون الأبناء لتخصيص محتواها وسلوكها.

function UserProfile(props) {
    return <h4>المستخدم: {props.name}</h4>;
}
// الاستخدام: <UserProfile name="مها شهوب" />

07. إدارة الحالة الداخلية (State باستخدام useState)

الخطاف الأساسي (Hook) لتخزين وتحديث البيانات المتغيرة داخل المكون وإعادة رسم الواجهة تلقائياً عند تغييرها.

import { useState } from 'react';

function Counter() {
    const [count, setCount] = useState(0);
    return <button onClick={() => setCount(count + 1)}>العداد: {count}</button>;
}

08. التأثيرات الجانبية وإدارة دورة الحياة (useEffect)

تنفيذ الأكواد المرتبطة بجلب البيانات من الخوادم، المؤقتات، أو التفاعل مع المتصفح عند تحميل أو تحديث المكون.

import { useEffect, useState } from 'react';

useEffect(() => {
    console.log("تم تحميل المكون بنجاح");
}, []); // مصفوفة فارغة لتنفيذ الكود مرة واحدة

09. معالجة الأحداث والتفاعل (Event Handling)

التعامل مع ضغطات الأزرار، إدخال النماذج، وحركات الفأرة بطريقة متوافقة مع المتصفحات.

function handleClick(e) {
    e.preventDefault();
    alert("تم النقر على الزر بنجاح!");
}
return <button onClick={handleClick}>انقر هنا</button>;

10. العرض الشرطي وعمليات التكرار (Conditional & Lists)

عرض العناصر بناءً على شروط منطقية (ternary operator) ومعالجة المصفوفات لعرض قوائم البيانات (map).

const books = ['قواعد البيانات', 'لغة C', '++C'];
return (
    <ul>
        {books.map((book, index) => <li key={index}>{book}</li>)}
    </ul>
);

11. مشاركة الحالة المتقدمة (Context API)

تجنب تمرير الخصائص عبر مستويات متعددة (Prop Drilling) ومشاركة البيانات العامة مثل ثيم الألوان وتسجيل الدخول.

import { createContext, useContext } from 'const';
const ThemeContext = createContext('light');
// استخدام الـ Context داخل المكونات الفرعية عبر useContext

12. إدارة الحالة المعقدة عبر Hook (useReducer)

الخطاف البديل لـ useState للتعامل مع الحالات المعقدة التي تحتوي على عمليات منطقية متعددة ومترابطة.

import { useReducer } from 'react';
const initialState = { count: 0 };
function reducer(state, action) {
    switch (action.type) {
        case 'increment': return { count: state.count + 1 };
        default: return state;
    }
}

13. تحسين الأداء (useMemo و useCallback)

تخزين نتائج العمليات الحسابية والدوال لمنع إعادة تنفيذها بلا داعٍ ورفع كفاءة التطبيق.

import { useMemo, useCallback } from 'react';
const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);

14. المراجع واستشعار العناصر (useRef)

الوصول المباشر لعناصر DOM الحقيقية أو تخزين قيم لا تتسبب في إعادة رسم المكون عند تحديثها.

import { useRef } from 'react';
const inputRef = useRef(null);
const focusInput = () => inputRef.current.focus();

15. بناء خطاطيف مخصصة (Custom Hooks)

تغليف المنطق البرمجي المتكرر في خطاف خاص لإعادة استخدامه في أي مكون آخر بكل سهولة.

function useLocalStorage(key, initialValue) {
    // منطق مخصص للتعامل مع LocalStorage
}

import { BrowserRouter, Routes, Route } from 'react-router-dom';
// تنظيم المسارات والصفحات الرئيسية للنظام

17. التعامل مع واجهات الأبعاد والـ APIs (Fetch & Axios)

جلب البيانات من الخوادم الخارجية وعرضها ديناميكياً داخل المكونات بكفاءة.

useEffect(() => {
    fetch('https://api.example.com/data')
        .then(res => res.json())
        .then(data => setData(data));
}, []);

18. إدارة النماذج والتحقق من المدخلات (Forms)

التحكم بحقول الإدخال، حفظ قيمها في الحالة (Controlled Components)، والتحقق من صحتها.

<form onSubmit={handleSubmit}>
    <input type="text" value={username} onChange={(e) => setUsername(e.target.value)} />
    <button type="submit">إرسال</button>
</form>
