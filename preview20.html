هندسة واجهات المستخدم التفاعلية، Composition API، وإدارة الحالة من الجذور حتى الاحتراف؛ رؤية برمجية متكاملة للسرعة والمرونة.

01. مقدمة عن إطار العمل Vue.js وفلسفته

إطار عمل تدريجي (Progressive Framework) لتطوير واجهات المستخدم، يجمع بين بساطة HTML/CSS و قوة JavaScript، مع أداء عالٍ ونظام تفاعلي مرن تم تطويره بواسطة إيفان يو.

// الفلسفة: إطار عمل متطور وسهل التعلم يتكيف مع احتياجات المشروع البرمجي

02. إنشاء مشروع جديد عبر Vite والنظام الأساسي

استخدام أدوات البناء الحديثة Vite لإنشاء بيئة عمل Vue 3 متكاملة وسريعة الأداء.

# أوامر إنشاء وتشغيل مشروع Vue عبر موجه الأوامر
npm create vue@latest
cd my-vue-app
npm install
npm run dev

03. هيكلية مكونات Single File Components (SFC)

تقسيم المكون داخل ملف واحد يحوي ثلاثة أقسام رئيسية: القالب (<template>)، المنطق (<script setup>)، والتنسيق (<style>).

<template>
    <h1>{{ message }}</h1>
</template>
<script setup>
import { ref } from 'vue'
const message = ref('مرحباً بك في أكاديمية آفاق المعرفة التقنية')
</script>

04. تهيئة الحالة المتفاعلة عبر ref() و reactive()

طرق تعريف المتغيرات والحالات المتفاعلة (Reactivity) لضمان تحديث الواجهة تلقائياً عند تغير القيم.

import { ref, reactive } from 'vue'

const count = ref(0) // للقيم الفردية
const state = reactive({ name: 'مها شهوب', role: 'مهندسة برمجيات' }) // للكائنات

05. توجيهات العرض والربط (v-bind & v-model)

ربط خصائص العناصر بالمتغيرات (v-bind أو :) والربط الثنائي للنماذج وحقول الإدخال (v-model).

<input v-model="username" placeholder="أدخل الاسم..." />
<p>القيمة المدخلة: {{ username }}</p>

06. الجمل الشرطية (v-if, v-else, v-show)

التحكم في ظهور واختفاء العناصر في الواجهة بناءً على تحقق الشروط البرمجية.

<p v-if="isLoggedIn0">مرحباً بك مجدداً</p>
<p v-else>يرجى تسجيل الدخول</p>

07. حلقات التكرار وعرض القوائم (v-for)

معالجة مصفوفات البيانات وعرضها ديناميكياً داخل القوائم والجداول باستخدام التوجيه v-for.

<ul>
    <li v-for="(book, index) in books" :key="index">{{ book }}</li>
</ul>

08. معالجة الأحداث والتفاعل (v-on / @click)

استماع وتفعيل الأحداث البرمجية مثل النقر، الإرسال، وحركات الفأرة باستخدام الاختصار @.

<button @click="incrementCount">زيادة العداد</button>

09. الخصائص المحسوبة (Computed Properties)

إنشاء قيم مشتقة يتم حسابها تلقائياً وتخزينها مؤقتاً (Cached) بناءً على تغير المتغيرات المرتبطة بها.

import { ref, computed } from 'vue'
const price = ref(100)
const tax = computed(() => price.value * 0.15)

10. مراقبة التغييرات (Watchers)

تنفيذ عمليات أو مهام محددة فور رصد أي تغيير يطرأ على متغير أو حالة معينة.

import { ref, watch } from 'vue'
const searchQuery = ref('')
watch(searchQuery, (newValue) => {
    console.log('جاري البحث عن: ', newValue)
})

11. تمرير البيانات بين المكونات عبر Props

استقبال البيانات من المكونات الآباء إلى المكونات الأبناء باستخدام دالة defineProps.

<script setup>
defineProps({
    title: String,
    likes: Number
})
</script>

12. إصدار الأحداث والتواصل العكسي (Emits)

إرسال إشارات أو بيانات من المكون الابن إلى المكون الأب باستخدام دالة defineEmits.

<script setup>
const emit = defineEmits(['update'])
const triggerUpdate = () => emit('update', 'بيانات جديدة')
</script>

13. دورة حياة المكون (Lifecycle Hooks)

الخطافات التي تُنفذ في مراحل عمر المكون المختلفة مثل onMounted و onUnmounted.

import { onMounted } from 'vue'
onMounted(() => {
    console.log('تم تحميل المكون وعرضه في DOM بنجاح')
})

14. إدراج القوالب والمحتوى (Slots)

تمرير محتوى مرن وعناصر HTML من الأب لتضمينها داخل تصميم المكون الابن.

<template>
    <div class="card">
        <slot>محتوى افتراضي في حال عدم التمرير</slot>
    </div>
</template>

15. الخطاطيف المخصصة (Composables)

تغليف المنطق البرمجي المشترك في ملفات مستقلة لإعادة استخدامها بكفاءة (تشبه Custom Hooks في React).

// useCounter.js
import { ref } from 'vue'
export function useCounter() {
    const count = ref(0)
    const increment = () => count.value++
    return { count, increment }
}

16. إدارة الحالة المركزية عبر Pinia

مكتبة إدارة الحالة الرسمية والحديثة لتطبيقات Vue لإدارة البيانات العامة المشتركة بين كافة المكونات.

import { defineStore } from 'pinia'
export const useUserStore = defineStore('user', {
    state: () => ({ name: 'مها شهوب' }),
})

إعداد مسارات التطبيق وإنشاء نظام صفحات متعددة (SPA) بسلاسة تامة.

import { createRouter, createWebHistory } from 'vue-router'
// تعريف المسارات وربط المكونات بالصفحات

18. التعامل مع النماذج والتحقق من المدخلات

إدارة المدخلات، استخدام المعدلات (Modifiers مثل .trim و .number)، والتحقق من صحة البيانات.

<input v-model.trim="age" type="number" />

19. مشروع هندسي: تطبيق إدارة مهام متكامل (Vue Todo)

تطبيق عملي يجمع الحالة، الحلقات، النماذج، ومعالجة الأحداث لبناء نظام مهام تفاعلي.

<script setup>
import { ref } from 'vue'
const tasks = ref([])
const newTask = ref('')
const addTask = () => { if(newTask.value) tasks.value.push(newTask.value) }
</script>
