1. مقدمة في Python

Python هي لغة برمجة عالية المستوى، سهلة القراءة، متعددة الاستخدامات، وتستخدم في تطوير الويب، الأتمتة، تحليل البيانات، الذكاء الاصطناعي، التعلم الآلي، الشبكات، الأمن السيبراني والتطبيقات المختلفة.

توفر Python منظومة ضخمة من Packages وLibraries.

26. Inheritance وPolymorphism

Inheritance

        print("Animal sound")

28. Decorators

Decorator يسمح بإضافة سلوك إلى Function دون تعديل جسمها مباشرة. 

def log_call(func):

    def wrapper(*args, **kwargs):

        print("Calling:", func.__name__)

        return func(*args, **kwargs)

    return wrapper


@log_call
def hello():

    print("Hello Python")


hello()

48. Networking وSocket Programming

يمكن استخدام Python في برمجة الشبكات والتواصل بين الأجهزة باستخدام Sockets.

Socket Server مبسط

import socket

server = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

server.bind(
    ("127.0.0.1", 5000)
)

server.listen(1)

print("Server started")

connection, address = server.accept()

print("Connected:", address)

connection.close()
server.close()

مصطلحات مهمة

المصطلح المعنى
IP Address عنوان الجهاز على الشبكة.
Port رقم منطقي للخدمة.

TCP بروتوكول اتصال موثوق قائم على الاتصال.
UDP بروتوكول نقل لا يعتمد على إنشاء اتصال TCP.
