01 — مقدمة #C و.NET

#C لغة برمجة حديثة من Microsoft، صممت لبناء تطبيقات متنوعة تشمل تطبيقات سطح المكتب والويب والخدمات وواجهات API وتطبيقات الهاتف والألعاب وغيرها.

#C تعمل ضمن منظومة .NET، وهي منصة توفر Runtime ومكتبات وأدوات تطوير تسمح بتشغيل التطبيقات وبناء أنواع مختلفة من البرامج.

الفكرة الأساسية: #C هي اللغة، بينما .NET هي المنصة التي توفر البيئة والمكتبات وأدوات التشغيل والبناء.
العنصر وظيفته
#C لغة البرمجة التي نكتب بها الكود.
.NET SDK أدوات إنشاء وبناء وتشغيل المشاريع.
Runtime البيئة اللازمة لتشغيل التطبيق.
CLR بيئة تنفيذ كود .NET وإدارة الذاكرة والاستثناءات وغيرها.

02 — بيئة التطوير SDK وRuntime وCLR

عند تطوير برنامج #C نحتاج إلى أدوات لإنشاء المشروع وترجمته وتشغيله. أهمها .NET SDK، بينما Runtime يستخدم لتشغيل التطبيقات.

الفرق بين SDK وRuntime

SDK Runtime
إنشاء المشاريع تشغيل التطبيقات
Build Execution
يوفر أدوات CLI يوفر مكونات التشغيل

أوامر مهمة

dotnet --info
dotnet --list-sdks
dotnet --list-runtimes

03 — إنشاء أول مشروع #C

يمكن إنشاء مشروع Console من الطرفية باستخدام dotnet CLI. 

dotnet new console -n MyFirstApp
cd MyFirstApp
dotnet run

الأمر الأول ينشئ مشروعاً جديداً، والثاني يدخل إلى مجلد المشروع، والثالث يبني التطبيق ويشغله.

أبسط برنامج

Console.WriteLine("Hello C#");

04 — بنية المشروع وملف csproj

مشروع #C يحتوي على ملفات المصدر والإعدادات والمراجع والحزم. ملف csproj هو ملف المشروع ويحتوي على معلومات مهمة عن Target Framework والحزم وبعض خيارات البناء. 

<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net8.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

</Project>
إصدار TargetFramework في المثال مجرد مثال؛ استخدمي الإصدار المتاح والمناسب لبيئة التطوير لديك.

05 — المتغيرات والثوابت

المتغير هو مكان في الذاكرة يحمل قيمة يمكن تغييرها أثناء تشغيل البرنامج. أما الثابت const فقيمته تحدد وقت الترجمة ولا يمكن تغييرها بعد تعريفها. 

string name = "Maha";
int age = 30;
double price = 99.90;
bool active = true;

const double Pi = 3.1415926535;

قواعد تسمية المتغيرات

  • يجب ألا يبدأ الاسم برقم.
  • يمكن استخدام الحروف والأرقام وunderscore.
  • #C حساسة لحالة الأحرف.
  • يفضل استخدام أسماء واضحة مثل studentName بدلاً من x.

06 — أنواع البيانات

#C لغة ذات نظام أنواع قوي. كل قيمة لها نوع يحدد العمليات التي يمكن إجراؤها عليها وطريقة تخزينها.

النوع الاستخدام
int الأعداد الصحيحة.
long الأعداد الصحيحة الأكبر.
double الأعداد العشرية.
decimal القيم المالية والحسابات التي تحتاج دقة عشرية.
bool true أو false.
char حرف واحد.
string النصوص.
object نوع أساسي يمكنه الإشارة إلى قيم مختلفة.

07 — Value Types وReference Types

من المفاهيم الأساسية في #C الفرق بين Value Types وReference Types. Value Type يخزن القيمة نفسها، بينما Reference Type يحتوي متغيره على مرجع إلى كائن موجود في الذاكرة.

Value Type Reference Type
int class
double string
bool array
struct object
enum delegate

08 — التحويل Casting وParsing

نحتاج إلى تحويل البيانات عندما تكون القيمة من نوع مختلف عن النوع المطلوب. يوجد فرق بين Casting وParsing وConversion. 

string text = "25";

if (int.TryParse(text, out int age))
{
    Console.WriteLine(age);
}

double x = 10.8;
int y = (int)x;

Console.WriteLine(y);
TryParse مفيد عندما تكون البيانات القادمة من المستخدم أو ملف أو API وقد تكون غير صالحة للتحويل.

10 — الشروط if وelse

تستخدم الشروط لاتخاذ قرار بناءً على قيمة أو تعبير منطقي. 

int age = 20;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Minor");
}

11 — switch وSwitch Expressions

switch مناسب عندما نريد التعامل مع مجموعة من الحالات المحددة. 

int day = 2;

switch (day)
{
    case 1:
        Console.WriteLine("Saturday");
        break;

    case 2:
        Console.WriteLine("Sunday");
        break;

    default:
        Console.WriteLine("Unknown");
        break;
}

Switch Expression

string result = day switch
{
    1 => "Saturday",
    2 => "Sunday",
    _ => "Unknown"
};

12 — الحلقات Loops

الحلقات تسمح بتكرار تنفيذ مجموعة من التعليمات. 

for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}

foreach (var item in new[] { 10, 20, 30 })
{
    Console.WriteLine(item);
}

int x = 0;

while (x < 5)
{
    Console.WriteLine(x);
    x++;
}

13 — المصفوفات Arrays

المصفوفة تخزن مجموعة من العناصر من النوع نفسه، ويبدأ فهرسها عادة من الصفر. 

int[] numbers = { 10, 20, 30, 40 };

Console.WriteLine(numbers[0]);

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

14 — النصوص Strings

string من أكثر الأنواع استخداماً في التطبيقات، ويقدم عمليات البحث والتقطيع والاستبدال والتحويل والمقارنة. 

string name = "Maha Shahoub";

Console.WriteLine(name.Length);
Console.WriteLine(name.ToUpper());
Console.WriteLine(name.ToLower());
Console.WriteLine(name.Contains("Maha"));
Console.WriteLine(name.StartsWith("Maha"));
Console.WriteLine(name.Replace("Maha", "Engineer"));

String Interpolation

string name = "Maha";
int age = 30;

string message = $"My name is {name} and my age is {age}";

15 — StringBuilder

StringBuilder مناسب عند بناء نص كبير عبر عمليات إضافة وتعديل متكررة. يقلل من إنشاء عدد كبير من كائنات string المؤقتة في بعض السيناريوهات. 

using System.Text;

var builder = new StringBuilder();

builder.Append("C#");
builder.Append(" ");
builder.Append("Programming");

Console.WriteLine(builder.ToString());

16 — الدوال Methods

الدالة تجمع مجموعة من التعليمات في وحدة قابلة لإعادة الاستخدام. يمكن أن تستقبل Parameters وتعيد Return Value. 

static int Add(int a, int b)
{
    return a + b;
}

int result = Add(10, 20);

Console.WriteLine(result);

17 — Parameters وArguments

Parameter هو المتغير الموجود في تعريف الدالة، بينما Argument هي القيمة التي نمررها عند استدعائها. 

static void ShowUser(string name, int age)
{
    Console.WriteLine($"{name} - {age}");
}

ShowUser("Maha", 30);

18 — ref وout وin وparams

توفر #C عدة طرق متقدمة لتمرير المعاملات. 

static void Increment(ref int value)
{
    value++;
}

static bool TryParseAge(
    string text,
    out int age)
{
    return int.TryParse(text, out age);
}

static int Sum(params int[] values)
{
    return values.Sum();
}

int number = 10;

Increment(ref number);

if (TryParseAge("25", out int age))
{
    Console.WriteLine(age);
}

Console.WriteLine(Sum(1, 2, 3, 4));

19 — Optional وNamed Arguments

يمكن جعل بعض Parameters اختيارية، ويمكن تمرير Arguments بالاسم بدلاً من الاعتماد على ترتيبها. 

static void CreateUser(
    string name,
    int age = 18,
    bool active = true)
{
    Console.WriteLine(
        $"{name} - {age} - {active}");
}

CreateUser("Maha");

CreateUser(
    name: "Ali",
    active: false,
    age: 25);

20 — Structs

struct نوع قيمة Value Type مناسب لتمثيل كائنات صغيرة ذات قيمة. 

public struct Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

var point = new Point(10, 20);

Console.WriteLine(point.X);

enum يستخدم لتعريف مجموعة من القيم المحددة مسبقاً. 

enum UserRole
{
    Admin,

    Student

UserRole role = UserRole.Teacher;

if (role == UserRole.Teacher)

22 — Records

Records مناسبة لتمثيل البيانات، وتوفر سلوكاً مبنياً على القيمة في المقارنة بدلاً من الاعتماد فقط على هوية الكائن. 

public record User(
    int Id,
    string Name,
    string Email);

var user = new User(
    1,
    "Maha",
    "maha@example.com");

Console.WriteLine(user.Name);

23 — Classes وObjects

Class هو مخطط لإنشاء الكائنات. Object هو نسخة فعلية من Class. 

public class Student

    public string Name { get; set; }

    public string Greet()

var student = new Student("Maha");

Constructor يستخدم لتهيئة الكائن عند إنشائه.

    public Product(string name, decimal price)

var product =

25 — Fields وProperties

Field متغير داخل الكلاس، بينما Property توفر واجهة للوصول إلى البيانات ويمكنها التحكم في القراءة والكتابة. 

public class User
{
    private string _name = "";

    public string Name
    {
        get => _name;
        set
        {
            if (!string.IsNullOrWhiteSpace(value))
                _name = value;
        }
    }
}

26 — Access Modifiers

المحدد المعنى
public متاح من خارج النوع.
private متاح داخل النوع نفسه.
protected متاح داخل النوع والأنواع المشتقة.

27 — Encapsulation

التغليف يعني حماية الحالة الداخلية للكائن وعدم السماح بتعديلها بشكل عشوائي. يمكن تحقيق ذلك باستخدام private fields وproperties وmethods للتحقق من القيم. 

public class BankAccount
{
    private decimal _balance;

    public decimal Balance => _balance;

    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("Invalid amount");

        _balance += amount;
    }
}

28 — Inheritance

Inheritance يسمح لكلاس مشتق بإعادة استخدام خصائص وسلوك Class أساسي. 

public class Animal
{
    public string Name { get; set; } = "";

    public void Eat()
    {
        Console.WriteLine("Eating...");
    }
}

public class Dog : Animal
{
    public void Bark()
    {
        Console.WriteLine("Woof");
    }
}

var dog = new Dog();

dog.Name = "Max";
dog.Eat();
dog.Bark();

29 — Polymorphism

Polymorphism يسمح باستخدام مرجع من نوع أساسي للوصول إلى سلوك مختلف في الأنواع المشتقة. 

public class Animal
{
    public virtual void Sound()
    {
        Console.WriteLine("Animal sound");
    }
}

public class Dog : Animal
{
    public override void Sound()
    {
        Console.WriteLine("Woof");
    }
}

Animal animal = new Dog();

animal.Sound();

30 — Abstract Classes

Abstract class تستخدم كأساس لأنواع أخرى ولا يمكن عادة إنشاء instance مباشرة منها. 

public abstract class Shape
{
    public abstract double Area();
}

public class Circle : Shape
{
    public double Radius { get; }

    public Circle(double radius)
    {
        Radius = radius;
    }

    public override double Area()
    {
        return Math.PI * Radius * Radius;
    }
}

31 — Interfaces

Interface يحدد عقداً Contract يجب أن تلتزم به الأنواع التي تطبقه. وهو مهم جداً في تصميم الأنظمة وفصل المسؤوليات وDependency Injection. 

public interface IRepository<T>
{
    void Add(T item);
    T? GetById(int id);
}

public class UserRepository
    : IRepository<User>
{
    public void Add(User item)
    {
        Console.WriteLine("Added");
    }

    public User? GetById(int id)
    {
        return null;
    }
}

public record User(int Id, string Name);

32 — Composition

Composition تعني بناء كائن من خلال الاعتماد على كائنات أخرى بدلاً من الاعتماد دائماً على الوراثة. 

public class Engine
{
    public void Start()
    {
        Console.WriteLine("Engine started");
    }
}

public class Car
{
    private readonly Engine _engine;

    public Car(Engine engine)
    {
        _engine = engine;
    }

    public void Start()
    {
        _engine.Start();
    }
}

33 — Generics

Generics تسمح بكتابة كود يعمل مع أنواع متعددة مع الحفاظ على Type Safety. 

public class Box<T>
{
    public T Value { get; }

    public Box(T value)
    {
        Value = value;
    }
}

var numberBox = new Box<int>(100);
var textBox = new Box<string>("C#");

34 — Generic Constraints

يمكن وضع قيود على النوع T لتحديد الأنواع المقبولة داخل Generic. 

public class Repository<T>
    where T : class
{
    private readonly List<T> _items = new();

    public void Add(T item)
    {
        _items.Add(item);
    }
}

35 — Collections

Collections توفر هياكل لتخزين وإدارة مجموعات من البيانات.

Collection الاستخدام
List<T> قائمة مرتبة يمكن إضافة وحذف العناصر منها.
Dictionary<TKey,TValue> الوصول إلى قيمة باستخدام مفتاح.
HashSet<T> قيم فريدة بدون تكرار.
Queue<T> FIFO.
Stack<T> LIFO. 
var numbers = new List<int>
{
    10, 20, 30
};

numbers.Add(40);
numbers.Remove(20);

36 — Dictionary وHashSet

var users = new Dictionary<int, string>
{
    [1] = "Maha",
    [2] = "Ali"
};

if (users.TryGetValue(1, out string? name))
{
    Console.WriteLine(name);
}

var roles = new HashSet<string>
{
    "Admin",
    "Teacher",
    "Admin"
};

Console.WriteLine(roles.Count);

37 — Queue وStack

var queue = new Queue<string>();

queue.Enqueue("A");
queue.Enqueue("B");

Console.WriteLine(queue.Dequeue());

var stack = new Stack<string>();

stack.Push("A");
stack.Push("B");

Console.WriteLine(stack.Pop());

Queue تعمل بأسلوب First In First Out، بينما Stack تعمل بأسلوب Last In First Out.

38 — Lambda Expressions

Lambda طريقة مختصرة لكتابة دوال صغيرة تستخدم بكثرة مع LINQ والDelegates. 

Func<int, int> square =
    x => x * x;

Console.WriteLine(square(5));

39 — Delegates

Delegate يمثل مرجعاً إلى method بتوقيع معين، ويسمح بتمرير الدوال كقيم. 

public delegate int Operation(
    int a,
    int b);

static int Add(int a, int b)
{
    return a + b;
}

Operation operation = Add;

Console.WriteLine(
    operation(10, 20));

40 — Func وAction وPredicate

النوع الوظيفة
Func يمثل دالة تعيد قيمة.
Action يمثل دالة لا تعيد قيمة.
Predicate يمثل دالة تعيد bool. 
Func<int, int, int> add =
    (a, b) => a + b;

Action<string> show =
    text => Console.WriteLine(text);

Predicate<int> isEven =
    number => number % 2 == 0;

41 — Events

Events تستخدم في نظام الإشعارات داخل التطبيقات. الكائن يطلق الحدث، والكائنات الأخرى يمكنها الاشتراك فيه. 

public class Counter
{
    public event EventHandler? Changed;

    public void Update()
    {
        Changed?.Invoke(
            this,
            EventArgs.Empty);
    }
}

var counter = new Counter();

counter.Changed +=
    (sender, args) =>
    {
        Console.WriteLine("Changed");
    };

counter.Update();

42 — LINQ الأساسي

LINQ هي مجموعة تقنيات تسمح بالاستعلام عن Collections ومصادر بيانات بصياغة موحدة. 

var numbers = new[]
{
    1, 2, 3, 4, 5, 6
};

var even = numbers
    .Where(n => n % 2 == 0)
    .ToList();

foreach (var number in even)
{
    Console.WriteLine(number);
}

43 — LINQ المتقدم

var products = new[]
{
    new { Name = "Laptop", Price = 3000 },
    new { Name = "Mouse", Price = 100 },
    new { Name = "Keyboard", Price = 250 }
};

var result = products
    .Where(p => p.Price > 200)
    .OrderByDescending(p => p.Price)
    .Select(p => new
    {
        p.Name,
        p.Price,
        WithTax = p.Price * 1.15m
    })
    .ToList();

عمليات مهمة

44 — Pattern Matching

Pattern Matching تسمح بفحص النوع والقيمة والبنية بطريقة أكثر وضوحاً. 

object value = 25;

if (value is int number && number > 18)
{
    Console.WriteLine("Adult number");
}
string result = value switch
{
    int n when n >= 18 => "Adult",
    int => "Number",
    string => "Text",
    _ => "Unknown"
};

45 — Exception Handling

Exceptions تستخدم للتعامل مع الأخطاء التي تحدث أثناء التشغيل. 

try
{
    int result = 10 / 0;
}
catch (DivideByZeroException ex)
{
    Console.WriteLine(ex.Message);
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
finally
{
    Console.WriteLine("Finished");
}
لا تستخدم catch عام لإخفاء الأخطاء. سجل الخطأ وتعامل معه وفق طبيعة التطبيق.

    : Exception

    public InsufficientBalanceException(
        string message)

47 — Nullable Reference Types

Nullable Reference Types تساعد المبرمج على اكتشاف احتمالية وجود null أثناء الترجمة.

    name ?? "Unknown";

علامة ? تعني أن القيمة يمكن أن تكون null. أما ?? فتستخدم لتحديد قيمة بديلة عند وجود null.

69 — CancellationToken

CancellationToken يسمح بإلغاء عملية طويلة بطريقة منظمة بدلاً من قتل التنفيذ بطريقة عشوائية. 

static async Task WorkAsync(
    CancellationToken token)
{
    for (int i = 0; i < 10; i++)
    {
        token.ThrowIfCancellationRequested();

        await Task.Delay(500, token);
    }
}

using var cts =
    new CancellationTokenSource();

await WorkAsync(cts.Token);

  • تخلص من الموارد غير المُدارة بطريقة صحيحة.
  • انتبه إلى Event Handlers التي قد تمنع بعض الكائنات من التحرير.
  • استخدم Profiling عند وجود مشكلة أداء حقيقية.

command.Parameters.AddWithValue(

97 — SOLID

SOLID مجموعة مبادئ تساعد في تصميم أنظمة قابلة للتوسع والصيانة.

المبدأ الفكرة
S — Single Responsibility مسؤولية واحدة واضحة للكلاس.
O — Open/Closed التوسعة دون تعديل غير ضروري في الكود الموجود.
L — Liskov Substitution الأنواع المشتقة يجب أن تحافظ على توقعات النوع الأساسي.
I — Interface Segregation واجهات صغيرة ومناسبة بدلاً من واجهة ضخمة.
D — Dependency Inversion الاعتماد على abstractions بدلاً من التفاصيل المباشرة.

99 — Clean Code

Clean Code لا يعني كتابة كود طويل أو قصير فقط، بل كتابة كود مفهوم وقابل للاختبار والصيانة.

  • استخدم أسماء واضحة.
  • اجعل الدوال صغيرة قدر الإمكان.
  • تجنب التكرار غير الضروري.
  • افصل المسؤوليات.
  • لا تضع أسرار النظام داخل المصدر.
  • اكتب تعليقات عندما تضيف معنى، وليس لوصف الواضح من الكود.
  • استخدم أدوات التحليل والاختبارات.

100 — Layered Architecture

الـLayered Architecture تقسم التطبيق إلى طبقات واضحة.

Presentation

واجهة المستخدم وHTTP Endpoints.

Application

تنسيق حالات الاستخدام والخدمات.

Domain

قواعد المجال والكيانات الأساسية.

Infrastructure

قاعدة البيانات والخدمات الخارجية والملفات.

101 — Clean Architecture

Clean Architecture تهدف إلى جعل قواعد العمل الأساسية أقل اعتماداً على التفاصيل الخارجية مثل قاعدة البيانات وواجهة المستخدم.

الفكرة المهمة هي أن اتجاه الاعتماد يكون نحو الداخل، بحيث لا يصبح Domain مرتبطاً مباشرة بتقنية قاعدة بيانات أو واجهة معينة.

102 — Microservices

Microservices تقسم النظام إلى خدمات مستقلة نسبياً، لكل خدمة مسؤولية محددة ويمكن نشرها وتطويرها بصورة مستقلة حسب التصميم.

Microservices ليست مجرد تقسيم المشروع إلى عدة APIs؛ فهي تضيف تحديات مثل الشبكات والمراقبة وتوزيع البيانات والنشر والتوافق بين الخدمات.

111 — المشروع الأول: نظام إدارة الطلاب

مشروع تدريبي مناسب لتطبيق الأساسيات، ويحتوي على Student Class وقائمة طلاب وعمليات إضافة وحذف وبحث وحساب متوسط الدرجات. 

public class Student
{
    public int Id { get; set; }

    public string Name { get; set; } = "";

    public double Grade { get; set; }
}

var students = new List<Student>
{
    new()
    {
        Id = 1,
        Name = "Maha",
        Grade = 95
    },
    new()
    {
        Id = 2,
        Name = "Ali",
        Grade = 82
    }
};

var excellent =
    students
        .Where(s => s.Grade >= 90)
        .ToList();

foreach (var student in excellent)
{
    Console.WriteLine(
        $"{student.Name}: {student.Grade}");
}
