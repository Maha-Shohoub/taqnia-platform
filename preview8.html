دليل SQL Server الشامل

من قواعد البيانات وT-SQL إلى الأداء والأمان والنسخ الاحتياطي وربط التطبيقات والمشاريع.

إعداد الكاتبة والمهندسة: مها شهوب

01. مقدمة SQL Server

SQL Server نظام RDBMS لإدارة قواعد البيانات، يدعم التخزين والاستعلام والمعاملات والأمان والنسخ الاحتياطي والأداء.

02. SSMS

SQL Server Management Studio أداة الإدارة وكتابة T-SQL وفحص قواعد البيانات وخطط التنفيذ.

03. إنشاء قاعدة بيانات

يمكن إنشاء قاعدة بيانات من SSMS أو T-SQL.

CREATE DATABASE SchoolDB;
GO
USE SchoolDB;
GO

04. Schemas

تنظم الكائنات وتساعد على فصل الصلاحيات.

CREATE SCHEMA Sales;
GO

05. Tables

الجداول هي أساس تخزين البيانات.

CREATE TABLE dbo.Students(
 StudentID INT IDENTITY(1,1) PRIMARY KEY,
 StudentName NVARCHAR(100) NOT NULL,
 City NVARCHAR(100),
 Grade DECIMAL(5,2)
);

06. أنواع البيانات

أهم الأنواع: INT وBIGINT وDECIMAL وVARCHAR وNVARCHAR وDATE وDATETIME2 وBIT وVARBINARY.

07. Primary Key

يحدد كل سجل بشكل فريد ويمنع التكرار.

08. Foreign Key

يربط جدولاً بآخر ويحافظ على التكامل المرجعي.

ALTER TABLE dbo.Students ADD ClassID INT;
ALTER TABLE dbo.Students ADD CONSTRAINT FK_Students_Classes FOREIGN KEY(ClassID) REFERENCES dbo.Classes(ClassID);

09. Constraints

PRIMARY KEY وFOREIGN KEY وNOT NULL وUNIQUE وCHECK وDEFAULT.

10. العلاقات

One-to-One وOne-to-Many وMany-to-Many. الأخيرة تحتاج جدولاً وسيطاً.

11. Normalization

تقليل التكرار ومشكلات التحديث من خلال تصميم علائقي منظم.

12. SELECT

استخراج البيانات.

SELECT StudentID,StudentName,Grade FROM dbo.Students;

13. WHERE

تصفية الصفوف.

SELECT StudentName,Grade FROM dbo.Students WHERE Grade>=50 AND City=N'Tripoli';

14. DISTINCT وTOP

DISTINCT يزيل التكرار وTOP يحدد عدد النتائج.

SELECT DISTINCT City FROM dbo.Students;
SELECT TOP (10) * FROM dbo.Students ORDER BY Grade DESC;

15. LIKE وIN وBETWEEN

بحث بالنمط أو مجموعة قيم أو نطاق.

SELECT * FROM Students WHERE StudentName LIKE N'م%' AND City IN(N'Tripoli',N'Misrata') AND Grade BETWEEN 70 AND 100;

16. NULL

استخدم IS NULL وIS NOT NULL بدلاً من = NULL.

SELECT * FROM Students WHERE City IS NULL;

17. CASE

منطق شرطي داخل الاستعلام.

SELECT StudentName,Grade,CASE WHEN Grade>=50 THEN N'ناجح' ELSE N'راسب' END AS Result FROM Students;

18. Aggregate Functions

COUNT وSUM وAVG وMIN وMAX لتلخيص البيانات.

SELECT COUNT(*) Total,AVG(Grade) AverageGrade,MIN(Grade) MinGrade,MAX(Grade) MaxGrade FROM Students;

19. GROUP BY

تجميع الصفوف.

SELECT City,COUNT(*) TotalStudents FROM Students GROUP BY City;

20. HAVING

تصفية نتائج GROUP BY.

SELECT City,AVG(Grade) AvgGrade FROM Students GROUP BY City HAVING AVG(Grade)>=70;

21. INNER JOIN

جلب الصفوف المتطابقة من جدولين.

SELECT s.StudentName,c.ClassName FROM Students s INNER JOIN Classes c ON s.ClassID=c.ClassID;

22. LEFT JOIN

إظهار كل صفوف الجدول الأيسر حتى بدون تطابق.

SELECT c.ClassName,s.StudentName FROM Classes c LEFT JOIN Students s ON c.ClassID=s.ClassID;

23. RIGHT وFULL JOIN

RIGHT يعكس LEFT، وFULL يعرض المطابق وغير المطابق من الجانبين.

24. CROSS وSelf JOIN

CROSS ينتج التركيبات، وSelf JOIN يربط الجدول بنفسه.

25. Subqueries

استعلام داخل استعلام.

SELECT StudentName,Grade FROM Students WHERE Grade>(SELECT AVG(Grade) FROM Students);

26. CTE

نتيجة مؤقتة باسم واضح.

WITH HighGrades AS(SELECT * FROM Students WHERE Grade>=80) SELECT * FROM HighGrades;

27. UNION

UNION يزيل التكرار وUNION ALL يحتفظ به.

28. INSERT

إضافة سجل.

INSERT INTO Students(StudentName,City,Grade) VALUES(N'Ali',N'Tripoli',85);

29. UPDATE

تعديل البيانات مع اختبار WHERE قبل التنفيذ.

UPDATE Students SET Grade=Grade+5 WHERE StudentID=10;

30. DELETE

حذف البيانات مع اختبار WHERE.

DELETE FROM Students WHERE StudentID=10;

31. MERGE

مزامنة بيانات، ويجب اختباره بعناية مقارنة بالعمليات المنفصلة.

32. Views

حفظ استعلام كواجهة منطقية.

CREATE VIEW dbo.vw_Students AS SELECT StudentName,Grade FROM dbo.Students WHERE Grade>=50;
GO

33. Stored Procedures

إجراءات قابلة لإعادة الاستخدام وتدعم Parameters.

CREATE PROCEDURE dbo.GetStudentsByCity @City NVARCHAR(100) AS BEGIN SET NOCOUNT ON; SELECT * FROM Students WHERE City=@City; END;
GO
EXEC dbo.GetStudentsByCity N'Tripoli';

34. Parameters

تفصل القيم عن SQL وتساعد على الأمان وإعادة الاستخدام.

35. Functions

دوال تعيد قيمة أو جدولاً، ويجب مراعاة الأداء.

36. Table-Valued Functions

دالة تعيد جدولاً.

CREATE FUNCTION dbo.GetStudents(@MinGrade DECIMAL(5,2)) RETURNS TABLE AS RETURN(SELECT * FROM Students WHERE Grade>=@MinGrade);

37. Triggers

تعمل تلقائياً عند INSERT أو UPDATE أو DELETE، واستخدامها يحتاج تخطيطاً جيداً.

38. Transactions

تنفذ عدة عمليات كوحدة واحدة.

BEGIN TRANSACTION;
UPDATE Accounts SET Balance=Balance-100 WHERE AccountID=1;
UPDATE Accounts SET Balance=Balance+100 WHERE AccountID=2;
COMMIT TRANSACTION;

39. ACID

Atomicity وConsistency وIsolation وDurability هي خصائص المعاملات.

40. Locks

تحمي البيانات أثناء التزامن. طول المعاملة والفهارس يؤثران على التزاحم.

41. Deadlocks

تحدث عند انتظار معاملات بعضها بعضاً. تحسين ترتيب الوصول وتقليل مدة المعاملة يساعد.

42. Isolation Levels

Read Uncommitted وRead Committed وRepeatable Read وSerializable وSnapshot.

43. Indexes

تسرع القراءة المناسبة لكنها تزيد مساحة التخزين وتكلفة التعديل.

44. Clustered Index

يوجد واحد لكل جدول ويحدد ترتيب تخزين الصفوف المنطقي.

45. Nonclustered Index

فهرس منفصل عن ترتيب الصفوف.

CREATE INDEX IX_Students_City ON dbo.Students(City);

46. Composite Index

فهرس بأكثر من عمود.

CREATE INDEX IX_Students_City_Grade ON dbo.Students(City,Grade);

47. Execution Plans

توضح طريقة تنفيذ الاستعلام وعمليات Seek وScan وJoin.

48. Query Optimization

حلل الخطة، حسّن الفهارس، استخدم شروطاً واضحة وحدد الأعمدة المطلوبة.

49. Statistics

تساعد Optimizer في تقدير توزيع البيانات وعدد الصفوف.

50. SQL Server Agent

جدولة المهام الإدارية مثل النسخ الاحتياطي والتنظيف في الإصدارات الداعمة.

51. Jobs

تتكون من Steps وSchedules وسجل تنفيذ.

52. Backup

النسخ الاحتياطي جزء أساسي من الاستمرارية.

BACKUP DATABASE SchoolDB TO DISK='D:\Backups\SchoolDB.bak' WITH INIT,COMPRESSION;

53. Restore

الاستعادة يجب اختبارها دورياً.

RESTORE DATABASE SchoolDB FROM DISK='D:\Backups\SchoolDB.bak' WITH RECOVERY;

54. Recovery Models

Simple وFull وBulk-Logged حسب متطلبات الاستعادة وسجل المعاملات.

55. Import وExport

نقل البيانات مع مراجعة الأنواع والمفاتيح والتكرار.

56. SQL Server وExcel

SQL Server مصدر مركزي ويمكن استخدام Excel للتحليل والعرض.

57. Access وSQL Server

Access يمكن أن يعمل Front-End وSQL Server Back-End.

58. VB.NET

استخدم SqlConnection وSqlCommand وParameters.

Using cn As New SqlConnection(connectionString)
 cn.Open()
 Using cmd As New SqlCommand("SELECT StudentName FROM Students WHERE StudentID=@id",cn)
  cmd.Parameters.Add("@id",SqlDbType.Int).Value=1
  Using r=cmd.ExecuteReader()
   While r.Read(): Console.WriteLine(r("StudentName")): End While
  End Using
 End Using
End Using

59. C#

استخدم SqlConnection وSqlCommand وParameters.

using var cn=new SqlConnection(connectionString);
await cn.OpenAsync();
using var cmd=new SqlCommand("SELECT StudentName FROM Students WHERE StudentID=@id",cn);
cmd.Parameters.Add("@id",SqlDbType.Int).Value=1;

60. Java

استخدم JDBC وPreparedStatement.

PreparedStatement ps=conn.prepareStatement("SELECT StudentName FROM Students WHERE StudentID=?");
ps.setInt(1,1);

61. Python

استخدم pyodbc أو SQLAlchemy مع Parameters.

62. PHP

استخدم SQLSRV أو PDO_SQLSRV وPrepared Statements.

63. REST API

البنية: Client ثم API ثم Service ثم SQL Server. لا تجعل المتصفح يتصل مباشرة بقاعدة البيانات.

64. Security

Authentication وAuthorization وأقل صلاحية وحماية الأسرار والتحديثات والنسخ الاحتياطي.

65. GRANT وDENY وREVOKE

إدارة الصلاحيات.

GRANT SELECT ON dbo.Students TO AppReader;
DENY DELETE ON dbo.Students TO AppReader;
REVOKE SELECT ON dbo.Students FROM AppReader;

66. SQL Injection

استخدم Parameters ولا تدمج مدخلات المستخدم داخل SQL.

67. JSON

دعم JSON عبر OPENJSON وأدوات JSON الأخرى.

DECLARE @json NVARCHAR(MAX)=N'{"name":"Ali","grade":85}';
SELECT * FROM OPENJSON(@json) WITH(name NVARCHAR(100) '$.name',grade INT '$.grade');

68. Temporary Tables

مفيدة للنتائج الوسيطة.

CREATE TABLE #TopStudents(StudentID INT,Grade DECIMAL(5,2));
INSERT INTO #TopStudents SELECT StudentID,Grade FROM Students WHERE Grade>=90;
SELECT * FROM #TopStudents;

69. Table Variables

مناسبة لبعض النتائج الصغيرة، والاختيار يعتمد على الحجم والخطة.

70. Window Functions

تحسب على مجموعة مرتبطة دون اختزال الصفوف.

SELECT StudentName,City,Grade,AVG(Grade) OVER(PARTITION BY City) CityAverage FROM Students;

71. ROW_NUMBER وRANK

ترتيب الصفوف.

SELECT StudentName,Grade,ROW_NUMBER() OVER(ORDER BY Grade DESC) RowNo,RANK() OVER(ORDER BY Grade DESC) RankNo FROM Students;

72. LEAD وLAG

مقارنة الصف الحالي بالسابق أو التالي.

SELECT SaleDate,Amount,LAG(Amount) OVER(ORDER BY SaleDate) PreviousAmount FROM Sales;

73. Dynamic SQL

استخدم sp_executesql مع Parameters.

DECLARE @sql NVARCHAR(MAX)=N'SELECT * FROM Students WHERE City=@City'; EXEC sys.sp_executesql @sql,N'@City NVARCHAR(100)',@City=N'Tripoli';
