دليل HTML الشامل

مرجع عملي متكامل لتعلم HTML من الصفر حتى بناء صفحات ومشاريع ويب منظمة، مع HTML5 وSemantic HTML وForms وSEO وAccessibility والتكامل مع CSS وJavaScript وPHP وقواعد البيانات.

HTML5 Web Development Semantic Web SEO & ARIA Responsive

01. مقدمة HTML

تعريف HTML ودورها الأساسي في هيكلة صفحات ومواقع الويب.

مثال عملي
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="UTF-8"><title>صفحتي</title></head>
<body><h1>مرحباً بالعالم</h1></body>
</html>

02. ما هي HTML؟

لغة توصيف النصوص التشعبية (HyperText Markup Language) وليست لغة برمجة تقليدية.

مثال عملي
<h1>عنوان الرئيسي</h1>
<p>فقرة نصية توضيحية.</p>
<a href="https://example.com">رابط توضيحي</a>

03. HTML5

الإصدار الأحدث والأكثر تطوراً من HTML، ويدعم الوسائط المتعددة والعناصر الدلالية الحديثة.

مثال عملي
<!doctype html>
<html lang="ar" dir="rtl">
<body><main><article>محتوى HTML5 الحديث</article></main></body>
</html>

04. بنية صفحة HTML

الهيكل القياسي الذي تتكون منه أي صفحة ويب لضمان عملها بشكل صحيح.

مثال عملي
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"></head>
<body><h1>بنية الصفحة الأساسية</h1></body>
</html>

05. DOCTYPE

تعريف نوع المستند لإخبار المتصفح بإصدار HTML المستخدم.

مثال عملي
<!DOCTYPE html>

06. html وhead وbody

العناصر الجذرية ورأس المستند وجسم الصفحة الظاهر للمستخدم.

مثال عملي
<html lang="ar" dir="rtl">
<head><title>موقعي التقني</title></head>
<body><p>المحتوى الظاهر</p></body>
</html>

07. العناوين والفقرات

استخدام وسوم العناوين (h1-h6) والفقرات (p) لتنظيم النصوص.

مثال عملي
<h1>العنوان الرئيسي</h1>
<h2>عنوان فرعي</h2>
<p>هذه فقرة نصية داخل المستند.</p>

08. تنسيق النصوص

وسوم لتأكيد أو تمييز النصوص مثل strong وem وmark وcode.

مثال عملي
<p><strong>تنبيه:</strong> احفظ الملف بصيغة <code>.html</code></p>

09. الروابط

ربط الصفحات بعضها ببعض أو الانتقال لمواقع خارجية عبر عنصر a.

مثال عملي
<a href="about.html">من نحن</a>
<a href="https://example.com" target="_blank" rel="noopener">موقع خارجي</a>

10. الصور

إدراج الصور في الصفحة باستخدام عنصر img والخصائص src وalt.

مثال عملي
<img src="images/logo.png" alt="شعار المنصة" width="150" height="150">

11. الصوت والفيديو

تضمين الوسائط الصوتية والمرئية مباشرة دون برامج خارجية.

مثال عملي
<video controls width="500"><source src="video.mp4" type="video/mp4">متصفحك لا يدعم الفيديو.</video>

12. القوائم

إنشاء قوائم نقطية (ul) أو مرقمة (ol).

مثال عملي
<ul><li>عنصر أول</li><li>عنصر ثاني</li></ul>
<ol><li>خطوة أولى</li><li>خطوة ثانية</li></ol>

13. الجداول

عرض البيانات في صفوف وأعمدة منظمة باستخدام table وtr وth وtd.

مثال عملي
<table><thead><tr><th>المادة</th><th>التقدير</th></tr></thead><tbody><tr><td>HTML</td><td>ممتاز</td></tr></tbody></table>

14. النماذج Forms

جمع مدخلات المستخدمين وإرسالها للمعالجة.

مثال عملي
<form action="process.php" method="POST"><input type="text" name="username" required><button type="submit">إرسال</button></form>

15. Input وأنواعه

أنواع حقول الإدخال المتعددة مثل text وemail وpassword وnumber.

مثال عملي
<input type="text" placeholder="الاسم">
<input type="email" placeholder="البريد">
<input type="password" placeholder="كلمة المرور">

16. Buttons

أزرار الإرسال وإعادة التعيين والأزرار المخصصة لتنفيذ وظائف JavaScript.

مثال عملي
<button type="submit">إرسال البيانات</button>
<button type="button">زر تفاعلي</button>

17. Select وTextarea

قوائم الاختيار المنسدلة ومساحات إدخال النصوص الطويلة.

مثال عملي
<select name="city"><option>طرابلس</option><option>بنغازي</option></select>
<textarea name="notes" rows="4"></textarea>

18. Labels

تسميات حقول الإدخال لتحسين تجربة المستخدم وإمكانية الوصول.

مثال عملي
<label for="username">اسم المستخدم:</label>
<input id="username" type="text">

19. Validation

التحقق المبدئي من صحة المدخلات في المتصفح مثل required وminlength.

مثال عملي
<input type="email" required>
<input type="text" minlength="5" required>

20. Semantic HTML

استخدام العناصر الدلالية لوصف معنى المحتوى لمحركات البحث والمتصفحات.

مثال عملي
<header>الرأس</header>
<main>المحتوى الرئيسي</main>
<footer>التذييل</footer>

21. header وnav وmain

عناصر بنية الصفحة الرئيسية لرأس الموقع، التنقل، والمحتوى الأساسي.

مثال عملي
<header><h1>عنوان الموقع</h1></header>
<nav><a href="#">الرئيسية</a></nav>
<main><p>المحتوى</p></main>

22. section وarticle

تخصيص الأقسام والمقالات المستقلة ضمن المحتوى.

مثال عملي
<section><h2>قسم الدروس</h2><article><p>مقال تعليمي.</p></article></section>

23. aside وfooter

المحتوى الجانبي التكميلي وتذييل الصفحة والمعلومات القانونية.

مثال عملي
<aside>روابط ذات صلة</aside>
<footer>جميع الحقوق محفوظة © 2026</footer>

24. div وspan

حاويات عامة لتقسيم العناصر أو تنسيق أجزاء من النصوص.

مثال عملي
<div class="card"><p>نص مع <span class="highlight">كلمة مميزة</span></p></div>

25. HTML Entities

عرض الرموز الخاصة مثل أقواس الوسوم ورموز النشر داخل المحتوى.

مثال عملي
&lt;p&gt;هذا نص برمجي&lt;/p&gt;
&copy; 2026 جميع الحقوق محفوظة

26. Comments

كتابة تعليقات توضيحية داخل الكود البرمجي لا يراها المستخدم.

مثال عملي
<!-- هذا تعليق توضيحي لقسم الهيدر -->

27. Attributes

الخصائص التي تضاف لعناصر HTML لتحديد سلوكها أو خصائصها.

مثال عملي
<a href="page.html" target="_blank">رابط جديد</a>

28. id وclass

تحديد معرف فريد (id) أو فئة عامة (class) لتنسيق واستهداف العناصر.

مثال عملي
<div id="main-header" class="box-card">محتوى</div>

29. Meta Tags

وسوم الوصف والترميز وضبط التوافقية لمحركات البحث والمتصفحات.

مثال عملي
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="وصف الموقع">

30. SEO في HTML

تحسين ظهور الموقع في محركات البحث عبر العناوين والوصف والوسوم المناسبة.

مثال عملي
<title>عنوان الصفحة الاحترافي للبحث</title>
<meta name="description" content="ملخص دقيق لمحتوى الصفحة...">

31. Open Graph

وسوم لتحسين ظهور روابط الموقع عند مشاركتها على وسائل التواصل الاجتماعي.

مثال عملي
<meta property="og:title" content="عنوان المشاركة">
<meta property="og:image" content="image.jpg">

32. Favicon

إضافة أيقونة مصغرة للموقع تظهر في تبويب المتصفح.

مثال عملي
<link rel="icon" type="image/png" href="favicon.png">

33. Responsive HTML

جعل صفحات الويب متجاوبة مع كافة مقاسات الشاشات والهواتف الذكية.

مثال عملي
<meta name="viewport" content="width=device-width, initial-scale=1.0">

34. Accessibility

إتاحة الوصول لذوي الاحتياجات الخاصة واستخدام القارئات الصوتية بكفاءة.

مثال عملي
<img src="chart.png" alt="رسم بياني لتطور المبيعات">

35. ARIA

خصائص إضافية لتوصيف العناصر الديناميكية لواجهات المستخدم المتقدمة.

مثال عملي
<button aria-label="إغلاق النافذة">✕</button>

36. iframe

تضمين صفحة ويب خارجية داخل المستند الحالي.

مثال عملي
<iframe src="https://example.com" title="موقع خارجي" width="100%" height="300"></iframe>

37. Google Maps وEmbeds

تضمين الخرائط والخدمات التفاعلية الجاهزة في صفحات الويب.

مثال عملي
<iframe src="https://www.google.com/maps/embed?pb=..." title="موقعنا" loading="lazy"></iframe>

38. Canvas

عنصر للرسم البرمجي الثنائي والثلاثي الأبعاد باستخدام JavaScript.

مثال عملي
<canvas id="myCanvas" width="400" height="200"></canvas>

39. SVG

رسومات متجهة عالية الجودة قابلة للتكبير دون فقدان الوضوح.

مثال عملي
<svg height="100" width="100"><circle cx="50" cy="50" r="40" fill="blue"/></svg>

40. HTML APIs

واجهات البرمجة المتاحة في المتصفح وتعمل بالتكامل مع لغة HTML.

مثال عملي
<script>console.log(navigator.language);</script>

41. Local Storage

التخزين المحلي الدائم للبيانات البسيطة في متصفح المستخدم.

مثال عملي
<script>localStorage.setItem("user", "مها");</script>

42. Session Storage

التخزين المؤقت للبيانات طوال فترة جلسة تصفح المتصفح الحالية.

مثال عملي
<script>sessionStorage.setItem("sessionID", "12345");</script>

43. Drag & Drop

تفعيل ميزة السحب والإفلات للعناصر داخل صفحة الويب.

مثال عملي
<div draggable="true">اسحب هذا العنصر</div>

44. Geolocation

تحديد الموقع الجغرافي لجهاز المستخدم بموافقته.

مثال عملي
<script>navigator.geolocation.getCurrentPosition(pos => console.log(pos.coords));</script>

45. Web Workers

تشغيل السكريبتات الثقيلة في الخلفية دون التأثير على سرعة الواجهة.

مثال عملي
<script>const worker = new Worker('worker.js');</script>

46. Web Components

بناء وابتكار عناصر HTML مخصصة وقابلة لإعادة الاستخدام.

مثال عملي
<my-element></my-element>

47. Templates

قوالب HTML مخفية يتم استدعاؤها وتعبئتها برمجياً عند الحاجة.

مثال عملي
<template id="cardTpl"><div class="card">محتوى القالب</div></template>

48. Forms متقدمة

استخدام الحقول المتقدمة وdatalist ومجموعات الحقول.

مثال عملي
<input list="browsers">
<datalist id="browsers"><option value="Chrome"><option value="Firefox"></datalist>

49. Data Attributes

خصائص data-* لتخزين بيانات مخصصة قابلة للقراءة عبر dataset.

مثال عملي
<div data-id="105" data-role="admin">بيانات المستخدم</div>

50. تحميل الملفات

السماح للمستخدمين برفع الملفات والمستندات عبر حقل الـ file.

مثال عملي
<input type="file" name="uploadFile" accept=".pdf,.png">

51. HTML مع CSS

تنسيق وتجميل صفحات HTML باستخدام لغة الأنماط الشاملة CSS.

مثال عملي
<link rel="stylesheet" href="style.css">

52. HTML مع JavaScript

إضافة التفاعلية والحيوية والحركات لصفحات HTML عبر JavaScript.

مثال عملي
<script src="main.js"></script>

53. HTML مع Bootstrap

استخدام إطار العمل الشهير Bootstrap لتسريع وتسهيل التصميم المتجاوب.

مثال عملي
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

54. HTML مع jQuery

اختصار وتسهيل التعامل مع DOM والأحداث عبر مكتبة jQuery.

مثال عملي
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>

55. HTML مع PHP

دمج كود HTML مع لغة الخادم PHP لإنشاء صفحات ديناميكية.

مثال عملي
<h1><?php echo "مرحباً بكم"; ?></h1>

56. HTML مع MySQL

عرض البيانات المسترجعة من قواعد بيانات MySQL داخل جداول HTML.

مثال عملي
<table><tr><td><?php /* عرض بيانات قاعدة البيانات */ ?></td></tr></table>

57. صفحات تسجيل الدخول

تصميم واجهات نموذجية لتسجيل دخول المستخدمين بأمان.

مثال عملي
<form><input type="email" placeholder="البريد"><input type="password" placeholder="كلمة المرور"><button>دخول</button></form>

58. صفحات التسجيل

تصميم نماذج تسجيل حساب جديد للمستخدمين الجدد في المنصة.

مثال عملي
<form><input type="text" placeholder="الاسم الكامل"><input type="email" placeholder="البريد"><button>تسجيل</button></form>

59. لوحة التحكم

بناء الهيكل العام للوحة تحكم إدارية متكاملة ومترابطة.

مثال عملي
<aside class="admin-sidebar">القائمة الجانبية</aside><main class="admin-content">الإحصائيات</main>

60. تصميم مكتبة إلكترونية

تخطيط هيكل موقع مكتبة رقمية لعرض الكتب والمؤلفات.

مثال عملي
<section class="book-grid"><article class="book-card">كتاب التقنية</article></section>

61. تصميم منصة تعليمية

هيكلة صفحات الدورات التدريبية والدروس والمسارات التعليمية.

مثال عملي
<div class="course-player"><video controls></video><div class="playlist">الدروس</div></div>

62. تصميم متجر إلكتروني

بناء واجهات عرض المنتجات، عربة التسوق، وصفحات إتمام الشراء.

مثال عملي
<div class="product-card"><img src="item.jpg" alt="منتج"><h3>اسم المنتج</h3><button>إضافة للسلة</button></div>

63. مشروع موقع شخصي

تصميم سيرة ذاتية وموقع شخصي احترافي لعرض المهارات والأعمال.

مثال عملي
<section id="hero"><h1>مرحباً، أنا مهندسة برمجيات</h1></section>

64. مشروع موقع كتب

بناء منصة متكاملة لعرض وتحميل الكتب التقنية والتعليمية.

مثال عملي
<div class="library-catalog"><h2>سلسلة أساسيات التقنية</h2></div>

65. مشروع منصة تعليمية

تطوير قالب متكامل لمنصة أكاديمية لتعليم البرمجة وتقنية المعلومات.

مثال عملي
<section class="academy-hero"><h2>أكاديمية آفاق المعرفة التقنية</h2></section>

66. تحسين SEO

أفضل الممارسات البرمجية لرفع ظهور الموقع في نتائج محركات البحث.

مثال عملي
<h1>العنوان الرئيسي (H1 واحد فقط في الصفحة)</h1>

67. تحسين سرعة الصفحة

تسريع أداء صفحات الويب بتقليل حجم الأصول وتحسين الاستدعاءات.

مثال عملي
<img src="image.jpg" loading="lazy" alt="تحميل متأخر للصور">

68. حماية النماذج

تأمين النماذج ضد هجمات الاختراق وحماية مدخلات المستخدمين.

مثال عملي
<input type="hidden" name="csrf_token" value="xyz123token">

69. أخطاء HTML الشائعة

تجنب الأخطاء البرمجية الشائعة مثل نسيان إغلاق الوسوم أو تداخلها.

مثال عملي
<p>خطأ: <strong>نص تداخل</p></strong> <!-- يجب إغلاق الوسم الداخلي أولاً -->

70. أفضل الممارسات

قواعد كتابة كود نظيف، منظم، وقابل للصيانة والاشتراك.

مثال عملي
<!-- استخدم الحروف الصغيرة لأسماء الوسوم والخصائص -->
<div class="container"></div>

71. تنظيم ملفات المشروع

الترتيب الهيكلي السليم لمجلدات المشروع (css, js, images).

مثال عملي
project/
├── index.html
├── css/style.css
├── js/main.js
└── images/logo.png

72. HTML5 الحديثة

التعرف على أحدث الإضافات والخصائص المعاصرة في معايير HTML5.

مثال عملي
<dialog id="myModal">محتوى النافذة الحوارية المنبثقة</dialog>

73. مشاريع تطبيقية كاملة

تطبيق عملي شامل يدمج كافة مهارات HTML لبناء موقع متكامل.

مثال عملي
<!-- دمج كافة العناصر الدلالية، النماذج، والوسائط في مشروع متكامل -->

74. اختصارات HTML

أبرز اختصارات محرر النصوص لزيادة سرعة كتابة الكود البرمجي (Emmet).

مثال عملي
ul>li*3  <!-- اختصار لإنشاء قائمة من 3 عناصر -->

75. المرجع السريع لـ HTML

خلاصة أهم الوسوم والخصائص الأساسية للرجوع السريع أثناء التطوير.

مثال عملي
<!DOCTYPE html>, <html>, <head>, <body>, <header>, <main>, <footer>, <a>, <img>, <form>
