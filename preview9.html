دليل HTML الشامل

مرجع عملي متكامل لتعلم HTML من الصفر حتى بناء صفحات ومشاريع ويب منظمة، مع HTML5 وSemantic HTML وForms وSEO وAccessibility والتكامل مع CSS وJavaScript وPHP وقواعد البيانات.

إعداد الكاتبة والمهندسة: مها شهوب

منصة آفاق المعرفة التقنية · مكتبة | مها شهوب · سلسلة أساسيات التقنية

01

مقدمة HTML

تعريف HTML ودورها في بناء هيكل صفحات الويب.

مثال عملي
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="UTF-8"><title>صفحتي</title></head>
<body><h1>مرحباً بالعالم</h1></body>
</html>
02

ما هي HTML؟

HTML اختصار HyperText Markup Language وهي لغة توصيف وليست لغة برمجة تقليدية.

مثال عملي
<h1>عنوان</h1>
<p>فقرة نصية.</p>
<a href="https://example.com">رابط</a>
03

HTML5

أهم ما قدمته HTML5 من عناصر دلالية ووسائط وميزات حديثة.

مثال عملي
<!doctype html>
<html lang="ar" dir="rtl">
<body><main><article>محتوى HTML5</article></main></body>
</html>
04

بنية صفحة HTML

الهيكل الأساسي للصفحة: DOCTYPE وhtml وhead وbody.

مثال عملي
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"></head>
<body><h1>عنوان الصفحة</h1></body>
</html>
05

DOCTYPE

يحدد معيار المستند ويستخدم في HTML5 بالشكل المختصر.

مثال عملي
<!DOCTYPE html>
06

html وhead وbody

html هو الجذر، head للمعلومات والموارد، وbody للمحتوى الظاهر.

مثال عملي
<html lang="ar" dir="rtl">
<head><title>موقعي</title></head>
<body><p>المحتوى</p></body>
</html>
07

العناوين والفقرات

استخدام h1 إلى h6 وp لبناء محتوى منظم.

مثال عملي
<h1>الدليل الشامل</h1>
<h2>مقدمة</h2>
<h3>مفهوم HTML</h3>
<p>HTML تبني هيكل الصفحة.</p>
08

تنسيق النصوص

عناصر دلالية مثل strong وem وmark وsmall وcode.

مثال عملي
<p><strong>مهم:</strong> استخدم <code>.html</code> لملفات HTML.</p>
09

الروابط

إنشاء روابط داخلية وخارجية وبريد إلكتروني.

مثال عملي
<a href="about.html">من نحن</a>
<a href="https://example.com" target="_blank" rel="noopener">موقع خارجي</a>
10

الصور

img مع src وalt وأبعاد مناسبة.

مثال عملي
<img src="images/logo.png" alt="شعار المنصة" width="180" height="180">
11

الصوت والفيديو

audio وvideo لتضمين الوسائط.

مثال عملي
<video controls width="600"><source src="lesson.mp4" type="video/mp4">متصفحك لا يدعم الفيديو.</video>
12

القوائم

القوائم غير المرتبة والمرتبة وقوائم التعريف.

مثال عملي
<ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul>
<ol><li>إنشاء الملف</li><li>كتابة الكود</li></ol>
13

الجداول

الجداول للبيانات الجدولية مع thead وtbody وth وtd.

مثال عملي
<table><caption>درجات الطلاب</caption><thead><tr><th>الاسم</th><th>الدرجة</th></tr></thead><tbody><tr><td>أحمد</td><td>90</td></tr></tbody></table>
14

النماذج Forms

form لجمع البيانات وإرسالها إلى الخادم أو JavaScript.

مثال عملي
<form action="save.php" method="post"><label for="name">الاسم</label><input id="name" name="name" required><button type="submit">حفظ</button></form>
15

Input وأنواعه

أنواع input الأساسية: text وemail وpassword وnumber وdate وfile وغيرها.

مثال عملي
<input type="text" name="name">
<input type="email" name="email">
<input type="password" name="password">
<input type="date" name="birth">
16

Buttons

أزرار submit وbutton وreset.

مثال عملي
<button type="submit">إرسال</button>
<button type="button">اختبار</button>
<button type="reset">مسح</button>
17

Select وTextarea

قوائم الاختيار والنصوص متعددة الأسطر.

مثال عملي
<select name="course"><option>HTML</option><option>CSS</option></select>
<textarea name="message" rows="5"></textarea>
18

Labels

ربط label بحقول النموذج لتحسين الاستخدام وإمكانية الوصول.

مثال عملي
<label for="email">البريد الإلكتروني</label>
<input id="email" name="email" type="email">
19

Validation

خصائص التحقق مثل required وminlength وmaxlength وpattern.

مثال عملي
<input type="email" required>
<input type="text" minlength="3" maxlength="50" required>
20

Semantic HTML

العناصر الدلالية مثل header وnav وmain وsection وarticle وfooter.

مثال عملي
<header>رأس الموقع</header>
<nav>روابط</nav>
<main><article>مقال</article></main>
<footer>حقوق النشر</footer>
21

header وnav وmain

بناء رأس الموقع والتنقل والمحتوى الرئيسي.

مثال عملي
<header><h1>آفاق المعرفة التقنية</h1></header>
<nav><a href="/">الرئيسية</a><a href="/books">الكتب</a></nav>
<main><h2>المحتوى</h2></main>
22

section وarticle

section للمجموعات الموضوعية وarticle للمحتوى المستقل.

مثال عملي
<section><h2>دروس HTML</h2><article><h3>الدرس الأول</h3><p>مقدمة.</p></article></section>
23

aside وfooter

aside للمحتوى الجانبي وfooter للمعلومات الختامية.

مثال عملي
<aside><h2>روابط سريعة</h2></aside>
<footer>إعداد مها شهوب</footer>
24

div وspan

حاويات عامة عند عدم وجود عنصر دلالي مناسب.

مثال عملي
<div class="card"><h2>عنوان</h2><p>نص <span class="highlight">مهم</span>.</p></div>
25

HTML Entities

عرض المحارف الخاصة باستخدام Entities.

مثال عملي
<p>&lt;h1&gt;عنوان&lt;/h1&gt;</p>
<p>HTML &amp; CSS</p>
26

Comments

كتابة تعليقات لا تظهر للزائر.

مثال عملي
<!-- قسم الكتب -->
<section id="books"><h2>الكتب</h2></section>
27

Attributes

الخصائص تضيف معلومات للعنصر مثل href وsrc وid وclass وrequired.

مثال عملي
<input type="text" id="username" class="field" required>
<a href="books.html" title="عرض الكتب">الكتب</a>
28

id وclass

id معرف فريد وclass يمكن استخدامه على عدة عناصر.

مثال عملي
<section id="about" class="card featured"><h2>عن المنصة</h2></section>
29

Meta Tags

أهم وسوم meta للترميز وviewport والوصف.

مثال عملي
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="دليل HTML شامل">
30

SEO في HTML

تحسين بنية الصفحة لمحركات البحث عبر title والوصف والعناوين والروابط وalt.

مثال عملي
<title>دليل HTML الشامل</title>
<meta name="description" content="تعلم HTML من الأساسيات إلى المشاريع">
<h1>دليل HTML الشامل</h1>
31

Open Graph

وسوم المشاركة الاجتماعية مثل og:title وog:description وog:image.

مثال عملي
<meta property="og:title" content="دليل HTML الشامل">
<meta property="og:description" content="مرجع HTML عربي">
<meta property="og:image" content="cover.jpg">
32

Favicon

إضافة أيقونة الموقع في المتصفح.

مثال عملي
<link rel="icon" type="image/png" href="images/favicon.png">
33

Responsive HTML

تهيئة الصفحة للأجهزة المحمولة مع viewport وبنية مناسبة.

مثال عملي
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<main><section><h2>محتوى متجاوب</h2></section></main>
34

Accessibility

العناوين وalt وlabels والأزرار الحقيقية تساعد على الوصول.

مثال عملي
<img src="chart.png" alt="رسم يوضح نمو المبيعات">
<label for="search">بحث</label><input id="search" type="search">
35

ARIA

استخدام ARIA عند الحاجة في المكونات المخصصة.

مثال عملي
<button aria-label="فتح القائمة">☰</button>
<nav aria-label="التنقل الرئيسي">...</nav>
36

iframe

تضمين موارد خارجية مع title ومراعاة الأمان والأداء.

مثال عملي
<iframe src="https://example.com" title="محتوى خارجي" loading="lazy" width="600" height="400"></iframe>
37

Google Maps وEmbeds

تضمين خرائط وفيديوهات وخدمات توفر كود embed رسمي.

مثال عملي
<iframe src="https://www.google.com/maps/embed?pb=..." title="موقعنا" loading="lazy"></iframe>
38

Canvas

مساحة رسم تعتمد على JavaScript للألعاب والرسومات.

مثال عملي
<canvas id="chart" width="500" height="250">لا يدعم المتصفح Canvas.</canvas>
<script>const ctx=document.getElementById("chart").getContext("2d");ctx.fillRect(20,20,150,80);</script>
39

SVG

رسومات متجهة يمكن تكبيرها دون فقدان الجودة.

مثال عملي
<svg width="200" height="100" viewBox="0 0 200 100"><rect x="10" y="10" width="180" height="80" rx="12"></rect></svg>
40

HTML APIs

HTML تتكامل مع Web APIs عبر JavaScript مثل Clipboard وStorage وGeolocation.

مثال عملي
<button id="copy">نسخ</button><script>document.getElementById("copy").onclick=()=>navigator.clipboard.writeText("HTML");</script>
41

Local Storage

تخزين بيانات نصية في المتصفح عبر JavaScript، مع تجنب الأسرار الحساسة.

مثال عملي
<script>localStorage.setItem("theme","dark");const theme=localStorage.getItem("theme");</script>
42

Session Storage

تخزين مؤقت مرتبط بجلسة التبويب.

مثال عملي
<script>sessionStorage.setItem("step","2");console.log(sessionStorage.getItem("step"));</script>
43

Drag & Drop

السحب والإفلات مع draggable وأحداث JavaScript.

مثال عملي
<div draggable="true">اسحبني</div><div id="dropzone">ضع العنصر هنا</div>
44

Geolocation

طلب موقع الجهاز بعد موافقة المستخدم عبر Geolocation API.

مثال عملي
<button onclick="getLocation()">معرفة موقعي</button>
<script>function getLocation(){navigator.geolocation.getCurrentPosition(p=>console.log(p.coords.latitude,p.coords.longitude));}</script>
45

Web Workers

تنفيذ مهام JavaScript مناسبة في خيط منفصل لتقليل تجميد الواجهة.

مثال عملي
<script>const worker=new Worker("worker.js");worker.postMessage("ابدأ");worker.onmessage=e=>console.log(e.data);</script>
46

Web Components

إنشاء عناصر مخصصة قابلة لإعادة الاستخدام عبر Custom Elements.

مثال عملي
<my-card></my-card>
<script>class MyCard extends HTMLElement{connectedCallback(){this.innerHTML="<h2>بطاقة مخصصة</h2>"}}customElements.define("my-card",MyCard);</script>
47

Templates

عنصر template لمحتوى لا يظهر مباشرة ويمكن نسخه بواسطة JavaScript.

مثال عملي
<template id="cardTemplate"><article class="card"><h2>عنوان</h2><p>نص</p></article></template>
48

Forms متقدمة

fieldset وlegend وdatalist وautocomplete وmultiple لتحسين النماذج.

مثال عملي
<fieldset><legend>بيانات التواصل</legend><input type="email" autocomplete="email" required><input type="file" multiple></fieldset>
49

Data Attributes

خصائص data-* لتخزين بيانات مخصصة قابلة للقراءة عبر dataset.

مثال عملي
<button data-book-id="25" data-category="programming">فتح الكتاب</button>
<script>console.log(document.querySelector("button").dataset.bookId);</script>
50

تحميل الملفات

رفع الملفات عبر input type=file وmultipart/form-data.

مثال عملي
<form action="/upload.php" method="post" enctype="multipart/form-data"><input type="file" name="book" accept=".pdf" required><button>رفع</button></form>
51

HTML مع CSS

HTML للهيكل وCSS للمظهر والتخطيط.

مثال عملي
<head><link rel="stylesheet" href="css/style.css"></head>
<body><div class="card">بطاقة</div></body>
52

HTML مع JavaScript

إضافة التفاعل ومعالجة DOM والأحداث.

مثال عملي
<button id="btn">اضغط</button><p id="result"></p><script>document.getElementById("btn").onclick=()=>document.getElementById("result").textContent="تم بنجاح";</script>
53

HTML مع Bootstrap

استخدام Bootstrap لتخطيطات ومكونات جاهزة.

مثال عملي
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container py-4"><div class="card p-3">بطاقة</div></div>
54

HTML مع jQuery

ربط HTML بمكتبة jQuery لمعالجة DOM والأحداث عند الحاجة.

مثال عملي
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<button id="btn">اضغط</button><script>$("#btn").on("click",()=>alert("مرحباً"));</script>
55

HTML مع PHP

إرسال البيانات إلى PHP ومعالجة الإخراج مع escaping مناسب.

مثال عملي
<form action="save.php" method="post"><input name="name" required><button>حفظ</button></form>
<?php echo htmlspecialchars($name ?? "", ENT_QUOTES, "UTF-8"); ?>
56

HTML مع MySQL

المتصفح لا يتصل مباشرة بـ MySQL؛ الخادم يتوسط بين HTML وقاعدة البيانات.

مثال عملي
<form action="save.php" method="post"><input name="title" required><button>إضافة</button></form>
<!-- save.php يتصل بقاعدة MySQL -->
57

صفحات تسجيل الدخول

نموذج الدخول، HTTPS، والتحقق الحقيقي على الخادم وتخزين كلمات المرور بالتجزئة.

مثال عملي
<form action="/login" method="post" autocomplete="on"><input name="email" type="email" autocomplete="username" required><input name="password" type="password" autocomplete="current-password" required><button>دخول</button></form>
58

صفحات التسجيل

نموذج إنشاء الحساب والتحقق من المدخلات على العميل والخادم.

مثال عملي
<form action="/register" method="post"><input name="name" minlength="2" required><input name="email" type="email" required><input name="password" type="password" minlength="8" required><button>إنشاء حساب</button></form>
59

لوحة التحكم

هيكل لوحة إدارية مع sidebar ومحتوى وإحصائيات.

مثال عملي
<div class="dashboard"><aside><nav><a href="dashboard.html">الرئيسية</a><a href="books.html">الكتب</a></nav></aside><main><h1>لوحة التحكم</h1><section><article><h2>عدد الكتب</h2><strong>120</strong></article></section></main></div>
60

تصميم مكتبة إلكترونية

هيكل مكتبة رقمية مع البحث وبطاقات الكتب.

مثال عملي
<main><section><h1>مكتبة | مها شهوب</h1><form><input type="search" placeholder="ابحث عن كتاب"></form><article><img src="book.jpg" alt="غلاف الكتاب"><h2>أساسيات HTML</h2><a href="read.html">قراءة الكتاب</a></article></section></main>
61

تصميم منصة تعليمية

تنظيم الدورات والوحدات والدروس داخل منصة تعليمية.

مثال عملي
<main><h1>منصة آفاق المعرفة التقنية</h1><section><h2>مسارات التعلم</h2><article><h3>تطوير الويب</h3><p>HTML ثم CSS ثم JavaScript.</p></article></section></main>
62

تصميم متجر إلكتروني

بطاقة منتج مع صورة وسعر وزر، مع تنفيذ العمليات الحساسة على الخادم.

مثال عملي
<article class="product"><img src="product.jpg" alt="وصف المنتج"><h2>منتج تقني</h2><p>السعر: 50 د.ل</p><button>أضف إلى السلة</button></article>
63

مشروع موقع شخصي

تقسيم الموقع إلى نبذة ومهارات ومشاريع وكتب وتواصل.

مثال عملي
<header><h1>مها شهوب</h1><nav><a href="#about">نبذة</a><a href="#projects">المشاريع</a></nav></header><main><section id="about"><h2>نبذة</h2><p>محتوى تعريفي.</p></section></main>
64

مشروع موقع كتب

صفحة كتب مع بحث وتصنيفات وروابط قراءة أو تنزيل مع صلاحيات الخادم.

مثال عملي
<section><h1>مكتبة الكتب</h1><form><input type="search" name="q" placeholder="ابحث"></form><article><h2>أساسيات البرمجة</h2><a href="read.html?id=1">قراءة</a></article></section>
65

مشروع منصة تعليمية

مشروع تطبيقي من صفحة رئيسية ودورة ودروس وتسجيل وتنقل.

مثال عملي
<header><nav><a href="index.html">الرئيسية</a><a href="courses.html">الدورات</a></nav></header><main><h1>دورة HTML</h1><ol><li><a href="lesson1.html">مقدمة</a></li><li><a href="lesson2.html">العناصر</a></li></ol></main>
66

تحسين SEO

عنوان ووصف وبنية عناوين وروابط داخلية وalt ومحتوى مفيد دون حشو كلمات مفتاحية.

مثال عملي
<title>تعلم HTML بالعربية | دليل شامل</title>
<meta name="description" content="دليل عملي لتعلم HTML من البنية الأساسية حتى النماذج والمشاريع.">
<h1>تعلم HTML</h1>
67

تحسين سرعة الصفحة

تقليل الصور والموارد واستخدام lazy loading وdefer وقياس الأداء فعلياً.

مثال عملي
<img src="cover.webp" alt="غلاف الكتاب" width="800" height="1000" loading="lazy">
<script src="app.js" defer></script>
68

حماية النماذج

التحقق في HTML ليس حماية كافية؛ التحقق الحقيقي يتم على الخادم مع HTTPS وحماية CSRF بحسب التطبيق.

مثال عملي
<form action="/save" method="post"><input name="title" maxlength="100" required><button>حفظ</button></form>
69

أخطاء HTML الشائعة

تجنب id المكرر والجداول للتخطيط وصور بلا alt وعناوين غير منظمة.

مثال عملي
<!-- خطأ: id مكرر -->
<div id="card">الأول</div><div id="card">الثاني</div>
70

أفضل الممارسات

استخدم semantic HTML، تنسيقاً ثابتاً، ملفات منفصلة، labels وalt وأزراراً وروابط صحيحة.

مثال عملي
<main><section aria-labelledby="title"><h1 id="title">دليل HTML</h1><p>بنية واضحة وسهلة الصيانة.</p></section></main>

HTML5 الحديثة

عناصر حديثة مثل details وsummary وpicture وtime وprogress وdialog حسب الحاجة ودعم المتصفحات.

مثال عملي
<details><summary>عرض التفاصيل</summary><p>محتوى قابل للفتح والإغلاق.</p></details>
<progress value="70" max="100">70%</progress>

مشاريع تطبيقية كاملة

مشاريع متدرجة لترسيخ المهارات: موقع شخصي، صفحة كتاب، نموذج، مكتبة، منصة، متجر ولوحة تحكم.

مثال عملي
<!DOCTYPE html>
<html lang="ar" dir="rtl"><head><meta charset="UTF-8"><title>مشروعي</title></head><body><header><h1>مشروعي</h1></header><main><h2>المحتوى</h2></main><footer>حقوق النشر</footer></body></html>
